4//! Post-consensus validation and owned-object conflict resolution for
5//! `UserTransactionV1` transactions.
6//!
7//! This module merges two formerly separate pipeline stages into a single pass:
8//!
9//! 1. **Semantic validation** — deduplication, already-executed check, structural validity,
10//!    attestation checks, and deny checks (deny lists, gas, ownership, coin deny list, Move
11//!    authenticator).
12//! 2. **Owned-object conflict resolution** (white-flag) — three-tier lock check and lock
13//!    acquisition.
14//!
15//! Processing both in one loop avoids iterating over every transaction twice.
16//! A transaction that can't acquire its object locks is dropped before the
17//! expensive validation. With more than one reader its inputs may have been
18//! read ahead of the loop, and that result is then left unused.
19//!
20//! # Per-transaction order within the loop
21//!
22//! 1. Non-`UserTransactionV1` — pass through unchanged.
23//! 2. Dedup by `ConsensusTransactionKey` — silent drop. A later copy of a user transaction with
24//!    other signatures or another attestation is validated when every earlier copy was dropped for
25//!    a reason that may come from its own signatures or attestation (see
26//!    `drop_may_come_from_signatures`).
27//! 3. Saved decisions, already-executed and deferred transactions:
28//!    - Replayed commit: a commit replayed after a restart repeats the decisions saved on its first
29//!      run. A saved drop is repeated without checks. Once the switch to executing synced
30//!      checkpoints after commit `L` is saved, a commit at or below `L` repeats a saved keep
31//!      without checks and takes no locks for it. Otherwise a saved keep is validated again unless
32//!      the transaction has executed or was deferred at an earlier commit.
33//!    - Already executed (typically by state sync): the transaction is **retained** as a
34//!      committee-agreed winner, not dropped: dropping it would make this validator's checkpoints
35//!      differ from those of the other validators. It registers the locks its own effects report
36//!      and skips re-validation. This applies only if the first run of this commit saved a keep for
37//!      it; otherwise it goes through the checks below like any other transaction, unless it was
38//!      deferred.
39//!    - Deferred at an earlier commit: the transaction is kept without checks and takes no new
40//!      locks. It was validated at the commit that kept it and still holds the locks it took there.
41//! 4. `validity_check()` — drop with error.
42//! 5. Attestation checks (attested transactions only): the attestor is the block author, the
43//!    attested units are within bounds, the attestor is not cut off as of the horizon, the gas
44//!    price and budget are within bounds, and the recorded versions fit the shared objects the
45//!    transaction names — drop with error. The attestation is the copy's own, so a later copy of
46//!    the digest is validated.
47//! 6. Three-tier lock conflict check (local HashMap → quarantine → DB) — drop with error, except a
48//!    lock held by the same transaction, which is exempt. Cheap; performed before expensive checks.
49//! 7. Transaction dependency (transactions with a dependency input only): decided from consensus
50//!    state, see `dependency_verdict` — drop with error when the dependency failed or is not
51//!    sequenced yet. A dependency whose outcome is not known yet keeps the transaction: it is
52//!    deferred at sequencing until the dependency is a root, and the execution scheduler then runs
53//!    it only after the dependency's effects are here.
54//! 8. `handle_transaction_validation_checks_at_commit()` — drop with error. An attested transaction
55//!    runs the input checks execution runs, gas included, and the checks on receiving objects; the
56//!    publish verifier stays at execution. Only reached when all locks are free. Its result may
57//!    have been computed ahead of the loop, see `ReadAhead`.
58//! 9. All passed — acquire locks in the local tracking map, keep transaction.
59//!
60//! Non-`UserTransactionV1` transactions pass through unchanged.
61//!
62//! # Which references get locked
63//!
64//! Step 6 probes every `ImmOrOwnedMoveObject` reference, but only genuinely
65//! owned references are locked — an immutable input never takes a new
66//! version, so its lock would hold until the epoch ends. Step 9 filters via
67//! the loaded objects, step 3 via the executed transaction's effects.
68

121/// The post-consensus validation decision for one transaction at one
122/// consensus commit.
123///
124/// Saved in the epoch tables, so its encoding must stay readable by other
125/// binaries within the epoch: variants carry no data and new ones go at the
126/// end.
127#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
128pub enum PostConsensusDecision {
129    /// The transaction stayed in the commit.
130    Kept,
131    /// The transaction was dropped.
132    Dropped,
133    /// The transaction was dropped because an input is not visible at the
134    /// commit's [horizon](crate::post_consensus_input_reader::reader::horizon)
135    /// yet. The digest can be kept when sequenced again, so the drop is not
136    /// its final status.
137    DroppedInputNotVisibleYet,
138    /// The copy of the transaction validated last was dropped for a reason
139    /// that may come from its own signatures, which other copies of the
140    /// digest do not share. Another copy can be kept when sequenced, so the
141    /// drop is not the final status of the digest.
142    DroppedCopy,
143}
144
145/// A post-consensus validation decision as saved, so a replay of the commit
146/// after a restart reaches the same decision.
147///
148/// The error of a drop is kept as BCS bytes and decoded on its own, so a
149/// binary that encodes `IotaError` differently still reads the decision.
150#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
151pub(crate) struct SavedPostConsensusDecision {
152    pub(crate) decision: PostConsensusDecision,
153    /// The BCS bytes of the drop's error; empty for a keep.
154    pub(crate) error: Vec<u8>,
155}
156
157impl SavedPostConsensusDecision {
158    pub(crate) fn kept() -> Self {
159        Self {
160            decision: PostConsensusDecision::Kept,
161            error: Vec::new(),
162        }
163    }
164
165    pub(crate) fn dropped(decision: PostConsensusDecision, error: &IotaError) -> Self {
166        Self {
167            decision,
168            error: bcs::to_bytes(error).expect("an IotaError should encode to BCS"),
169        }
170    }
171
172    /// The error of a saved drop, or `IotaError::Unknown` if this binary
173    /// cannot decode it.
174    pub(crate) fn error(&self) -> IotaError {
175        bcs::from_bytes(&self.error).unwrap_or_else(|e| {
176            IotaError::Unknown(format!(
177                "the saved error of a post-consensus drop cannot be decoded: {e}"
178            ))
179        })
180    }
181}

191/// Validates `UserTransactionV1` transactions and resolves owned-object
192/// conflicts in a single pass.
193///
194/// For each `UserTransactionV1`, in the order of `transactions`:
195/// - Runs deduplication, structural validity, lock conflict check, and deny checks (deny list, gas,
196///   ownership, coin deny list, Move authenticator).
197/// - If all checks pass, acquires owned-object locks in a local tracking map; immutable inputs are
198///   not locked, as an immutable input never takes a new version and its lock would hold until the
199///   epoch ends.
200/// - Drops the transaction (with an error) on any failure.
201/// - An already-executed transaction is **retained** (not dropped): it registers the locks its
202///   effects report and skips re-validation. Dropping it would make this validator's checkpoints
203///   differ from those of the other validators.
204/// - A transaction in `previously_deferred` is kept without checks and takes no new locks: the
205///   locks it took at the commit that kept it stay in place.
206///
207/// `transactions` must list every transaction after the transaction it depends on when both are
208/// in it, as `PostConsensusTxReorder::order_dependents_after_dependencies` leaves them, so a
209/// dependency is decided before its dependent is validated.
210///
211/// Copies of one digest with other signatures can come from different authors in one commit. The
212/// first copy is validated; a later one only while every earlier copy was dropped for a reason that
213/// may come from its own signatures. The digest's decision is that of the last copy validated, and
214/// only a kept copy stays in `transactions`.
215///
216/// Called only with the P-COOL flow on; the caller checks the flag.
217///
218/// The decision for every candidate is saved before returning, including keeps that the caller
219/// then defers, and a commit replayed after a restart repeats the saved decisions; step 3 of the
220/// module docs says which transactions are validated again. Panics if the saved decisions are
221/// incomplete, the candidates differ from the saved ones, a saved keep is now dropped, or a
222/// transaction dependency that is a root of the horizon or of an earlier commit has no effects.
223/// Once the switch to executing synced checkpoints after commit `L` is saved, also panics for a
224/// commit above `L`, or for a commit at or below `L` without saved decisions.
225///
226/// Non-`UserTransactionV1` transactions pass through unchanged.
227///
228/// # Arguments
229///
230/// * `authority_state` — Used for cache reads and deny checks.
231/// * `epoch_store` — Current epoch store (protocol config, lock storage, governance deny rules).
232/// * `commit_index` — The consensus commit being validated. Inputs are read as of this commit.
233/// * `previously_deferred` — The transactions deferred at earlier commits and reloaded into
234///   `transactions`, randomness-using ones included.
235/// * `transactions` — All sequenced transactions for this consensus commit; modified in-place.
236///
237/// # Returns
238///
239/// `Ok((dropped, locks, all_user_tx_digests))` where:
240/// - `dropped` — `(digest, error, decision)` for every semantically-invalid or lock-conflicting
241///   transaction, where `decision` is never `Kept`. Silent drops (duplicates) are **not** included.
242/// - `locks` — Owned-object locks acquired in this commit, to be stored in the consensus quarantine
243///   so subsequent commits can see them.
244/// - `all_user_tx_digests` — Every `UserTransactionV1` digest that passed dedup (both kept and
245///   dropped), once each. Used by the caller to release pre-consensus soft locks.
246pub async fn validate_and_resolve_conflicts(
247    authority_state: &AuthorityState,
248    epoch_store: &Arc<AuthorityPerEpochStore>,
249    commit_index: CommitIndex,
250    previously_deferred: &PreviouslyDeferredTransactions,
251    transactions: &mut Vec<VerifiedSequencedConsensusTransaction>,
252) -> IotaResult<(
253    Vec<(TransactionDigest, IotaError, PostConsensusDecision)>,
254    HashMap<ObjectReference, LockDetails>,
255    Vec<TransactionDigest>,
256)> {
257    // Keys of the transactions other than user transactions seen so far.
258    let mut seen_keys: HashSet<SequencedConsensusTransactionKey> = HashSet::new();
259    // The copies of each digest validated at this commit, in consensus order.
260    let mut validated_copies: HashMap<TransactionDigest, Vec<ValidatedCopy<'_>>> = HashMap::new();
261    let mut decisions = CommitDecisions::default();
262    // Every validated copy's digest, in consensus order: a digest appears once
263    // per copy validated.
264    let mut candidates = Vec::with_capacity(transactions.len());
265    // Locks acquired within this commit. Populated for every transaction that
266    // passes all checks; used by subsequent transactions' conflict checks.
267    let mut current_commit_locks: HashMap<ObjectReference, LockDetails> = HashMap::new();
268    // Index-parallel keep flags: true = keep, false = remove.
269    let mut keep = vec![true; transactions.len()];
270    // All UserTransactionV1 digests seen in this commit (both kept and dropped),
271    // used by the caller to release pre-consensus soft locks.
272    let mut all_user_tx_digests = Vec::with_capacity(transactions.len());
273
274    // One deny-rule snapshot for the whole commit, so every transaction in it
275    // is judged by the same set. This must be the consensus-derived set — local
276    // config can differ between validators and would fork the post-consensus
277    // decisions.
278    let governance_deny_rules = epoch_store.get_active_transaction_deny_rules();
279    let deny_config: &dyn DenyRuleConfig = governance_deny_rules.as_ref();
280
281    // The decisions saved when this commit was first validated, present only
282    // when it is replayed after a restart. A saved candidate list means every
283    // candidate has a saved decision.
284    let saved_candidates = epoch_store
285        .tables()?
286        .post_consensus_decision_candidates
287        .get(&commit_index)?;
288    // A node that switched to executing synced checkpoints after commit
289    // `last` replays only the commits up to it after a restart. Synced
290    // checkpoints have since written outputs without handler rows, which the
291    // reader cannot place, so these commits repeat their saved decisions.
292    let replaying_up_to_the_switch =
293        match epoch_store.last_commit_before_synced_checkpoint_execution()? {
294            Some(last) if commit_index > last => fatal!(
295                "commit {commit_index} validated after the switch to synced checkpoints \
296                 after commit {last}"
297            ),
298            Some(last) if saved_candidates.is_none() => fatal!(
299                "commit {commit_index} has no saved decisions although the switch to synced \
300                 checkpoints after commit {last} saved every decision up to it"
301            ),
302            Some(_) => true,
303            None => false,
304        };
305    // How many copies of each digest the first run validated. The decision
306    // of the last one is the digest's; the ones before it were dropped for
307    // their own signatures.
308    let mut saved_copies: HashMap<TransactionDigest, usize> = HashMap::new();
309    for digest in saved_candidates.iter().flatten() {
310        *saved_copies.entry(*digest).or_default() += 1;
311    }
312    let mut saved_decisions = HashMap::new();
313
314    // One reader for the whole commit, so every transaction in it is read as
315    // of the same commit index.
316    let reader = Arc::new(CommitIndexedReader::new(
317        authority_state.get_object_cache_reader().clone(),
318        epoch_store.clone(),
319        commit_index,
320    ));
321    // The attestors cut off as of this commit's horizon, read at the first
322    // attested transaction.
323    let mut attestors_cut_off: Option<BTreeSet<u8>> = None;
324
325    // The results of Check #6 read ahead of the loop, by position in
326    // `transactions`. A replayed commit reads nothing ahead: the inputs of
327    // a transaction it repeats a saved decision for may have left the store.
328    let readers = authority_state
329        .config
330        .post_consensus_validation_readers
331        .map_or_else(default_validation_readers, NonZeroUsize::get);
332    let mut read_ahead = if readers > 1 && saved_candidates.is_none() {
333        let _scope = monitored_scope("PostConsensusValidation::ReadAhead");
334        ReadAhead::new(
335            epoch_store,
336            commit_index,
337            previously_deferred,
338            transactions,
339            &mut attestors_cut_off,
340        )
341        .run(
342            authority_state,
343            epoch_store,
344            &reader,
345            &governance_deny_rules,
346            readers,
347        )
348        .await
349    } else {
350        HashMap::new()
351    };
352    let input_reads = &authority_state
353        .metrics
354        .consensus_handler_validation_input_reads;
355    let _scope = monitored_scope("PostConsensusValidation::Decide");
356
357    for (i, tx) in transactions.iter().enumerate() {
358        // Only validate UserTransactionV1; pass everything else through
359        // unchanged, once per key.
360        let Some((transaction, attestation)) = (match &tx.0.transaction {
361            SequencedConsensusTransactionKind::External(ext) => {
362                ext.kind.as_user_transaction_with_attestation()
363            }
364            SequencedConsensusTransactionKind::System(_) => None,
365        }) else {
366            if !seen_keys.insert(tx.0.key()) {
367                keep[i] = false;
368            }
369            continue;
370        };
371
372        let digest = *transaction.digest();
373        let signatures = transaction.data().signatures();
374
375        // Check #0: Dedup by digest.
376        // The same UserTransactionV1 may appear in DAG blocks from multiple
377        // validators within the same consensus commit. Silent drop — not added
378        // to `dropped`. A copy with other signatures or another attestation
379        // is validated while no earlier copy has decided the digest. A copy
380        // with the same signatures, attestation and, if attested, block
381        // author as one already validated would get the same decision.
382        let copy = (
383            signatures,
384            attestation.map(|attestation| (attestation, tx.0.certificate_author_index)),
385        );
386        let copies = validated_copies.entry(digest).or_default();
387        if copies.is_empty() {
388            all_user_tx_digests.push(digest);
389        } else if decisions.is_decided(&digest) || copies.contains(&copy) {
390            keep[i] = false;
391            continue;
392        }
393        copies.push(copy);
394        let copy_number = copies.len();
395        candidates.push(digest);
396
397        let saved = match &saved_candidates {
398            Some(_) => {
399                if copy_number < saved_copies.get(&digest).copied().unwrap_or_default() {
400                    keep[i] = false;
401                    continue;
402                }
403                match epoch_store.post_consensus_decision(commit_index, digest)? {
404                    Some(saved) => Some(saved),
405                    None => fatal!(
406                        "commit {commit_index} has a saved candidate list but no saved \
407                         validation decision for {digest:?}"
408                    ),
409                }
410            }
411            None => None,
412        };
413        let saved_decision = saved.as_ref().map(|saved| saved.decision);
414        if let Some(decision) = saved_decision {
415            saved_decisions.insert(digest, decision);
416        }
417        // A saved drop is replayed as is: the inputs it was decided on may
418        // have changed since.
419        if let Some(saved) = saved.filter(|saved| saved.decision != PostConsensusDecision::Kept) {
420            decisions.decide(digest, saved.decision, Some(saved.error()));
421            keep[i] = false;
422            continue;
423        }
424        // Its locks are not registered: nothing in this epoch reads them, as
425        // every transaction up to the switch repeats its saved decision and no
426        // commit after it is validated.
427        if replaying_up_to_the_switch && saved_decision == Some(PostConsensusDecision::Kept) {
428            debug!(
429                ?digest,
430                "Repeating the saved keep up to the synced checkpoint switch"
431            );
432            decisions.decide(digest, PostConsensusDecision::Kept, None);
433            continue;
434        }
435        // Validating it again could drop it, and the locks it took at the
436        // commit that kept it would then stay until the epoch ends. Later
437        // contenders find those locks in the quarantine or the lock table.
438        if previously_deferred.contains_key(&digest) {
439            debug!(
440                ?digest,
441                "Keeping a transaction deferred at an earlier commit without validating it again"
442            );
443            decisions.decide(digest, PostConsensusDecision::Kept, None);
444            continue;
445        }
446        // Whether a drop of this copy may come from its own signatures, so a
447        // later copy of the digest is validated.
448        let from_signatures = |check: FailedCheck<'_>| {
449            drop_may_come_from_signatures(transaction.data(), check, epoch_store.protocol_config())
450        };
451
452        // Check #1: Already executed (typically by state-sync before this node's
453        // consensus handler reached the commit). It is a committee-agreed winner, so
454        // keep it in the sequence to flow into checkpoint roots like on every other
455        // validator (dropping it would make this validator's checkpoint differ from
456        // those of the others). Register its owned-object locks so double-spend
457        // siblings still lose, then skip re-validation (#2/#5);
458        // the active scheduler's enqueue filter suppresses the re-execution.
459        //
460        // Effects alone do not show at which commit the transaction was kept,
461        // so only a saved keep at this commit skips validation; its consumed
462        // inputs may have left the live state by now. Without one, the
463        // commit-indexed reader decides, as on every other validator.
464        if saved_decision == Some(PostConsensusDecision::Kept)
465            && authority_state
466                .get_transaction_cache_reader()
467                .try_is_tx_already_executed(&digest)?
468        {
469            // Byte-based, so safe even though the inputs are already consumed.
470            let owned_inputs = filter_locked_inputs_by_effects(
471                authority_state,
472                &digest,
473                extract_owned_input_objects(tx)?,
474            )?;
475            for obj_ref in &owned_inputs {
476                // A winner cannot be out-locked: after the effects filter,
477                // every reference here was consumed by this transaction, so a
478                // lock held by a different tx is a consistency violation, not
479                // a conflict. (Flag off, immutable references, which are not
480                // consumed, stay in the set and weaken this invariant.)
481                if let Some(other) =
482                    find_existing_lock(obj_ref, &current_commit_locks, epoch_store)?
483                {
484                    if other != digest {
485                        fatal!(
486                            "already-executed transaction {:?} has owned input {:?} \
487                             locked by a different transaction {:?}",
488                            digest,
489                            obj_ref,
490                            other,
491                        );
492                    }
493                }
494                current_commit_locks.insert(*obj_ref, digest);
495            }
496            debug!(
497                ?digest,
498                num_owned_inputs = owned_inputs.len(),
499                "Transaction already executed; retained as checkpoint root, skipping re-validation"
500            );
501            // keep[i] stays true so the transaction remains in the sequence.
502            decisions.decide(digest, PostConsensusDecision::Kept, None);
503            continue;
504        }
505
506        // Checks #2 to #4 read no store. `ReadAhead::new` picks the
507        // transactions to read ahead with the same function.
508        let owned_inputs = match checks_reading_no_store(
509            epoch_store,
510            commit_index,
511            tx,
512            transaction,
513            attestation,
514            &mut attestors_cut_off,
515        ) {
516            Ok(owned_inputs) => owned_inputs,
517            Err((check, e)) => {
518                if check == NoStoreCheck::AttestorCutOff {
519                    // Every transaction in a cut-off attestor's blocks drops
520                    // here: debug, not warn.
521                    debug!(
522                        ?digest,
523                        commit_index,
524                        error = ?e,
525                        "attestor cut off for the rest of the epoch, dropping"
526                    );
527                    authority_state
528                        .metrics
529                        .consensus_handler_validation_attestor_cut_off_transactions
530                        .inc();
531                } else {
532                    warn!(
533                        ?digest,
534                        commit_index,
535                        attested = attestation.is_some(),
536                        ?check,
537                        error = ?e,
538                        "user transaction failed a post-consensus check that reads no store, dropping"
539                    );
540                }
541                let from_signatures = from_signatures(match check {
542                    NoStoreCheck::Validity => FailedCheck::Validity(&e),
543                    NoStoreCheck::Attestation | NoStoreCheck::AttestorCutOff => {
544                        FailedCheck::Attestation
545                    }
546                    NoStoreCheck::GasBounds => FailedCheck::Data,
547                    NoStoreCheck::OwnedInputs => FailedCheck::OwnedInputs,
548                });
549                decisions.drop_copy(digest, e, false, from_signatures);
550                keep[i] = false;
551                continue;
552            }
553        };
554
555        // Check #5: Three-tier lock conflict check.
556        // Cheap (HashMap + quarantine + DB lookups); performed before the
557        // deny checks so a conflicting transaction is dropped without them.
558        // Its inputs may have been read ahead all the same.
559        //
560        // Locks are keyed by full ObjectReference (id + version + digest), not just
561        // ObjectID. Two transactions referencing the same object at different
562        // versions will NOT conflict here — version freshness is checked in
563        // Check #6, where the commit-indexed reader rejects an input whose
564        // version is not live at the commit.
565        //
566        // Probing the raw set is safe though immutable inputs are never
567        // locked: acquisition never inserts one, and the lock tables are
568        // epoch-scoped while the protocol config is fixed per epoch, so no
569        // tier can hold a stale immutable lock.
570        //
571        // Tier 1: Local HashMap (current commit).
572        // Tier 2: Consensus quarantine (previous uncommitted commits).
573        // Tier 3: Persistent DB (committed data).
574        let mut conflict: Option<(ObjectReference, IotaError)> = None;
575        for obj_ref in &owned_inputs {
576            if let Some(locked_by) =
577                find_existing_lock(obj_ref, &current_commit_locks, epoch_store)?
578            {
579                // A lock held by this same transaction is its own lock from an
580                // earlier commit, not a conflict; Check #1 accepts one too.
581                // Same-commit duplicates cannot slip through here, since Check #0
582                // lets a later copy through only while no copy of the digest is
583                // kept.
584                if locked_by == digest {
585                    continue;
586                }
587
588                debug!(
589                    ?digest,
590                    ?obj_ref,
591                    ?locked_by,
592                    "Transaction conflicts with existing owned-object lock, dropping"
593                );
594                conflict = Some((
595                    *obj_ref,
596                    IotaError::ObjectLockConflict {
597                        obj_ref: *obj_ref,
598                        pending_transaction: locked_by,
599                    },
600                ));
601                break;
602            }
603        }
604        if let Some((obj_ref, e)) = conflict {
605            decisions.drop_copy(
606                digest,
607                e,
608                false,
609                from_signatures(FailedCheck::LockConflict(&obj_ref)),
610            );
611            keep[i] = false;
612            continue;
613        }
614
615        // Check #5b: Transaction dependency. Decided from consensus state only
616        // (see `dependency_verdict`), so every validator reaches the same
617        // verdict. The dependency is part of the signed data, so every copy of
618        // the digest shares the verdict.
619        if let Some(dependency) = transaction.transaction().transaction_dependency() {
620            match dependency_verdict(
621                dependency,
622                commit_index,
623                &decisions,
624                epoch_store,
625                authority_state,
626            )? {
627                DependencyVerdict::Satisfied | DependencyVerdict::Pending => {}
628                DependencyVerdict::Failed => {
629                    warn!(
630                        ?digest,
631                        commit_index,
632                        ?dependency,
633                        "transaction dependency did not succeed, dropping"
634                    );
635                    decisions.drop_copy(
636                        digest,
637                        UserInputError::TransactionDependencyFailed { digest: dependency }.into(),
638                        false,
639                        from_signatures(FailedCheck::Data),
640                    );
641                    keep[i] = false;
642                    continue;
643                }
644                DependencyVerdict::NotVisibleYet => {
645                    warn!(
646                        ?digest,
647                        commit_index,
648                        ?dependency,
649                        "transaction dependency not sequenced at this commit yet, dropping"
650                    );
651                    decisions.drop_copy(
652                        digest,
653                        UserInputError::TransactionDependencyNotFound { digest: dependency }.into(),
654                        true,
655                        from_signatures(FailedCheck::Data),
656                    );
657                    keep[i] = false;
658                    continue;
659                }
660            }
661        }
662
663        // Check #6: Validation and deny checks. Only reached when all locks are
664        // free. With one reader that skips the object loading for a
665        // transaction the lock conflict check drops. With more, its inputs
666        // were read ahead and the result is left unused.
667        //
668        // Safe to skip signature re-verification: the consensus block verifier
669        // (`IotaTxValidator::validate_transactions`) already called
670        // `verify_tx()` on every `UserTransactionV1` before accepting the
671        // block. Re-verifying here would not add safety — if a quorum
672        // committed a bad signature it indicates a protocol-level failure
673        // (2f+1 Byzantine/buggy validators), not something we can recover from
674        // by rejecting the transaction post-consensus. Doing so would also risk
675        // diverging from other honest validators.
676        //
677        // The result depends only on this copy and the state as of the
678        // horizon, never on the transactions before it in the commit, so one
679        // read ahead of the loop is the one a read here would give.
680        let checked = match read_ahead.remove(&i) {
681            Some(checked) => {
682                input_reads.with_label_values(&["ahead"]).inc();
683                checked
684            }
685            None => {
686                input_reads.with_label_values(&["inline"]).inc();
687                authority_state.handle_transaction_validation_checks_at_commit(
688                    &reader,
689                    &VerifiedTransaction::new_from_verified((*transaction).clone()),
690                    epoch_store,
691                    deny_config,
692                    VerifierLimitsSource::ProtocolConfig,
693                    attestation.is_some(),
694                )
695            }
696        };
697        // The input the reader dropped or did not see, and whether it did
698        // not see it.
699        let mut input_verdict: Option<(InputObjectKind, bool)> = None;
700        let mut denied_for_every_copy = false;
701        // Inputs read as of the commit. A missing input is reported with
702        // the error admission gives a missing input, which the transaction
703        // and quorum drivers retry: it drops the transaction from this
704        // commit only, the decision is saved as `Missing`, and a
705        // resubmission can be kept at a later commit. A dropped input is
706        // final for the digest, so it has its own error, which the drivers
707        // do not retry (a drop that may come from the copy's signatures is
708        // not sent to the waiters). The reason goes to the log. The Move
709        // authenticator runs at execution instead. Here only whether each
710        // account is one is checked, and its authenticator function field
711        // is read for the deny check of its package, both as of the
712        // horizon. The coin deny list is read as of the horizon too. An
713        // attested transaction runs the input checks execution runs, gas
714        // included, and the checks on receiving objects; the publish
715        // verifier stays at execution.
716        let checked = checked.and_then(|verdict| {
717            let verdicts = &authority_state
718                .metrics
719                .consensus_handler_validation_reader_verdicts;
720            match verdict {
721                ValidationAtCommit::Keep(owned) => {
722                    verdicts.with_label_values(&["keep", "none"]).inc();
723                    Ok(owned)
724                }
725                ValidationAtCommit::Drop(kind, reason) => {
726                    verdicts
727                        .with_label_values(&["drop", &format!("{:?}", reason.kind())])
728                        .inc();
729                    warn!(
730                        ?digest,
731                        commit_index,
732                        ?kind,
733                        ?reason,
734                        "input dropped by the commit-indexed reader"
735                    );
736                    input_verdict = Some((kind, false));
737                    Err(kind.not_available_at_commit_error().into())
738                }
739                ValidationAtCommit::Missing(kind, reason) => {
740                    verdicts
741                        .with_label_values(&["missing", &format!("{:?}", reason.kind())])
742                        .inc();
743                    warn!(
744                        ?digest,
745                        commit_index,
746                        ?kind,
747                        ?reason,
748                        "input not visible at this commit"
749                    );
750                    input_verdict = Some((kind, true));
751                    Err(kind.object_not_found_error().into())
752                }
753                ValidationAtCommit::AuthenticatorPackageDenied(error) => {
754                    denied_for_every_copy = true;
755                    Err(error)
756                }
757            }
758        });
759        let validated_owned_objects = match checked {
760            Ok(owned) => owned,
761            Err(e) => {
762                if e.is_storage_or_epoch_error() {
763                    return Err(e);
764                }
765                warn!(
766                    ?digest,
767                    commit_index,
768                    error = ?e,
769                    "UserTransactionV1 failed post-consensus deny checks, dropping"
770                );
771                let (missing, check) = match &input_verdict {
772                    Some((kind, missing)) => (*missing, FailedCheck::Input(kind)),
773                    None if denied_for_every_copy => (false, FailedCheck::Data),
774                    None => (false, FailedCheck::Other),
775                };
776                let from_signatures = from_signatures(check);
777                decisions.drop_copy(digest, e, missing, from_signatures);
778                keep[i] = false;
779                continue;
780            }
781        };
782
783        // All checks passed — acquire owned-object locks in local tracking.
784        // The validated set comes from loaded objects, so unlike the
785        // byte-derived `owned_inputs` it excludes immutable inputs, which must
786        // never be locked (see the module docs). It is a subset of `owned_inputs`,
787        // so every reference locked here was probed by Check #4 first.
788        for obj_ref in &validated_owned_objects {
789            current_commit_locks.insert(*obj_ref, digest);
790        }
791        // Log the acquired refs, not just their count, so the winner's locks
792        // are attributable per (object_id, version).
793        debug!(
794            ?digest,
795            num_owned_inputs = validated_owned_objects.len(),
796            owned_inputs = ?validated_owned_objects,
797            "Transaction passed post-consensus validation, acquired all object locks"
798        );
799        if attestation.is_some() {
800            authority_state
801                .metrics
802                .consensus_handler_validation_attested_transactions
803                .with_label_values(&["authority"])
804                .inc();
805        }
806        decisions.decide(digest, PostConsensusDecision::Kept, None);
807    }
808    // A result the loop did not take belongs to a transaction it dropped
809    // before Check #6. Its error, if any, is not this commit's.
810    input_reads
811        .with_label_values(&["unused"])
812        .inc_by(read_ahead.len() as u64);
813
814    let dropped: Vec<(TransactionDigest, IotaError, PostConsensusDecision)> = all_user_tx_digests
815        .iter()
816        .filter_map(|digest| match decisions.verdicts.get(digest) {
817            Some((decision, Some(error))) => Some((*digest, error.clone(), *decision)),
818            _ => None,
819        })
820        .collect();
821
822    match &saved_candidates {
823        Some(saved_candidates) => {
824            if *saved_candidates != candidates {
825                fatal!(
826                    "validation candidates of commit {commit_index} differ from the saved \
827                     ones: saved {saved_candidates:?}, now {candidates:?}"
828                );
829            }
830            for digest in &all_user_tx_digests {
831                let decision = decisions.verdicts.get(digest).map(|(decision, _)| decision);
832                let saved = saved_decisions.get(digest);
833                if saved != decision {
834                    fatal!(
835                        "validation decision for {digest:?} at commit {commit_index} \
836                         differs from the saved one: saved {saved:?}, now {decision:?}"
837                    );
838                }
839            }
840        }
841        None => {
842            // Every copy's entry carries the digest's decision.
843            let saved: Vec<_> = candidates
844                .iter()
845                .map(|digest| {
846                    let saved = match decisions
847                        .verdicts
848                        .get(digest)
849                        .expect("every validated copy decides its digest")
850                    {
851                        (decision, Some(error)) => {
852                            SavedPostConsensusDecision::dropped(*decision, error)
853                        }
854                        (_, None) => SavedPostConsensusDecision::kept(),
855                    };
856                    (*digest, saved)
857                })
858                .collect();
859            epoch_store.persist_post_consensus_decisions(commit_index, &saved)?;
860            if !saved.is_empty() {
861                fail_point!("crash-after-post-consensus-decisions");
862            }
863        }
864    }
865
866    if !dropped.is_empty() {
867        warn!(
868            num_dropped = dropped.len(),
869            num_retained = transactions
870                .iter()
871                .enumerate()
872                .filter(|(i, _)| keep[*i])
873                .count(),
874            "Post-consensus validation dropped transactions"
875        );
876    }
877
878    // Remove invalid/duplicate/conflicting entries using the parallel keep
879    // flags.
880    let mut iter = keep.into_iter();
881    transactions.retain(|_| iter.next().unwrap_or(true));
882
883    Ok((dropped, current_commit_locks, all_user_tx_digests))
884}

886/// How many readers validate a commit when the node config sets no number.
887fn default_validation_readers() -> usize {
888    static READERS: OnceLock<usize> = OnceLock::new();
889    *READERS.get_or_init(|| {
890        // Not from the host's cores, so a seed replays the same on every
891        // machine.
892        if cfg!(msim) {
893            4
894        } else {
895            validation_readers_for(
896                std::thread::available_parallelism().map_or(1, NonZeroUsize::get),
897            )
898        }
899    })
900}

902/// A third of `cores`, at least one and at most sixteen.
903fn validation_readers_for(cores: usize) -> usize {
904    (cores / 3).clamp(1, 16)

907/// The transactions of a commit whose Check #6 runs ahead of the validation
908/// loop. The readers take them one at a time.
909struct ReadAhead {
910    /// The position in the commit, the copy to check and whether it is
911    /// attested.
912    transactions: Vec<(usize, VerifiedTransaction, bool)>,
913    /// The next of `transactions` no reader has taken.
914    next: AtomicUsize,
915}
916
917impl ReadAhead {
918    /// Picks the transactions the loop is expected to take to Check #6: the
919    /// first copy of a digest that passes Checks #2 to #4, not deferred at an
920    /// earlier commit. The loop still runs every check itself, so a
921    /// transaction picked here that it drops earlier, as the loser of an
922    /// owned input is, costs only the reads. `attestors_cut_off` is the
923    /// loop's, filled here when an attested copy gets that far.
924    fn new(
925        epoch_store: &AuthorityPerEpochStore,
926        commit_index: CommitIndex,
927        previously_deferred: &PreviouslyDeferredTransactions,
928        transactions: &[VerifiedSequencedConsensusTransaction],
929        attestors_cut_off: &mut Option<BTreeSet<u8>>,
930    ) -> Self {
931        let mut digests = HashSet::new();
932        let mut picked = Vec::new();
933        for (i, tx) in transactions.iter().enumerate() {
934            let Some((transaction, attestation)) = (match &tx.0.transaction {
935                SequencedConsensusTransactionKind::External(ext) => {
936                    ext.kind.as_user_transaction_with_attestation()
937                }
938                SequencedConsensusTransactionKind::System(_) => None,
939            }) else {
940                continue;
941            };
942            let digest = *transaction.digest();
943            if digests.contains(&digest) || previously_deferred.contains_key(&digest) {
944                continue;
945            }
946            if checks_reading_no_store(
947                epoch_store,
948                commit_index,
949                tx,
950                transaction,
951                attestation,
952                attestors_cut_off,
953            )
954            .is_err()
955            {
956                continue;
957            }
958            // Only now, so a later copy is picked when this one failed.
959            digests.insert(digest);
960            picked.push((
961                i,
962                VerifiedTransaction::new_from_verified((*transaction).clone()),
963                attestation.is_some(),
964            ));
965        }
966        Self {
967            transactions: picked,
968            next: AtomicUsize::new(0),
969        }
970    }
971
972    /// Runs Check #6 for the picked transactions on up to `readers` threads,
973    /// this one included, and returns each result by the transaction's
974    /// position in the commit. A transaction without a result is read by the
975    /// loop.
976    async fn run(
977        self,
978        authority_state: &AuthorityState,
979        epoch_store: &Arc<AuthorityPerEpochStore>,
980        reader: &Arc<CommitIndexedReader>,
981        deny_rules: &Arc<DenyRuleSet>,
982        readers: usize,
983    ) -> HashMap<usize, IotaResult<ValidationAtCommit>> {
984        let this = Arc::new(self);
985        let others: Vec<_> = (1..readers.min(this.transactions.len()))
986            .map(|_| {
987                let this = this.clone();
988                let authority_state = authority_state.shared();
989                let epoch_store = epoch_store.clone();
990                let reader = reader.clone();
991                let deny_rules = deny_rules.clone();
992                let started = Arc::new(AtomicBool::new(false));
993                let handle = tokio::task::spawn_blocking({
994                    let started = started.clone();
995                    move || {
996                        // Set before the first transaction is taken.
997                        started.store(true, Ordering::SeqCst);
998                        this.read(&authority_state, &epoch_store, &reader, deny_rules.as_ref())
999                    }
1000                });
1001                (started, handle)
1002            })
1003            .collect();
1004        let mut results: HashMap<_, _> = this
1005            .read(authority_state, epoch_store, reader, deny_rules.as_ref())
1006            .into_iter()
1007            .collect();
1008        // Every transaction is taken by now, so a reader that has not started
1009        // took none and would find none. Its handle completes only once a
1010        // thread of the blocking pool is free, so the commit does not await
1011        // it.
1012        for (started, other) in others {
1013            if !started.load(Ordering::SeqCst) {
1014                other.abort();
1015                continue;
1016            }
1017            match other.await {
1018                Ok(read) => results.extend(read),
1019                Err(error) => {
1020                    if let Ok(panic) = error.try_into_panic() {
1021                        std::panic::resume_unwind(panic);
1022                    }
1023                }
1024            }
1025        }
1026        results
1027    }
1028
1029    /// Takes transactions until none is left and runs Check #6 for each.
1030    fn read(
1031        &self,
1032        authority_state: &AuthorityState,
1033        epoch_store: &Arc<AuthorityPerEpochStore>,
1034        reader: &CommitIndexedReader,
1035        deny_config: &dyn DenyRuleConfig,
1036    ) -> Vec<(usize, IotaResult<ValidationAtCommit>)> {
1037        let mut results = Vec::new();
1038        while let Some((i, transaction, attested)) = self
1039            .transactions
1040            .get(self.next.fetch_add(1, Ordering::SeqCst))
1041        {
1042            results.push((
1043                *i,
1044                authority_state.handle_transaction_validation_checks_at_commit(
1045                    reader,
1046                    transaction,
1047                    epoch_store,
1048                    deny_config,
1049                    VerifierLimitsSource::ProtocolConfig,
1050                    *attested,
1051                ),
1052            ));
1053        }
1054        results
1055    }
1056}

1058/// One of Checks #2 to #4, which read no store.
1059#[derive(Clone, Copy, Debug, PartialEq, Eq)]
1060enum NoStoreCheck {
1061    /// Check #2, `validity_check`.
1062    Validity,
1063    /// Check #3, the attestor, the units and the recorded versions of the
1064    /// attestation.
1065    Attestation,
1066    /// Check #3, the attestor is cut off for the rest of the epoch.
1067    AttestorCutOff,
1068    /// Check #3, the gas bounds of an attested transaction.
1069    GasBounds,
1070    /// Check #4, listing the owned inputs.
1071    OwnedInputs,
1072}
1073
1074/// Runs Checks #2 to #4 for one copy of a user transaction, in order. Returns
1075/// the owned inputs Check #4 lists, or the first check that failed with its
1076/// error. `attestors_cut_off` is filled when an attested copy gets that far.
1077fn checks_reading_no_store(
1078    epoch_store: &AuthorityPerEpochStore,
1079    commit_index: CommitIndex,
1080    tx: &VerifiedSequencedConsensusTransaction,
1081    transaction: &TransactionEnvelope,
1082    attestation: Option<&Attestation>,
1083    attestors_cut_off: &mut Option<BTreeSet<u8>>,
1084) -> Result<Vec<ObjectReference>, (NoStoreCheck, IotaError)> {
1085    let protocol_config = epoch_store.protocol_config();
1086
1087    // Check #2: Structural validity.
1088    transaction
1089        .validity_check(&epoch_store.tx_validity_check_context())
1090        .map_err(|e| (NoStoreCheck::Validity, e))?;
1091
1092    // Check #3: Attestation checks (attested transactions only).
1093    // The block signature transitively authenticates the attestation;
1094    // verify the claimed attestor matches the actual block author, that
1095    // the payload is not malformed and that the attestor is not cut off.
1096    if let Some(attestation) = attestation {
1097        let block_author = u8::try_from(tx.0.certificate_author_index)
1098            .expect("consensus committee indices should fit in a u8");
1099        let Attestation::Authority {
1100            authority_index, ..
1101        } = attestation;
1102        if *authority_index != block_author {
1103            return Err((
1104                NoStoreCheck::Attestation,
1105                IotaError::AttestationAuthorMismatch {
1106                    expected: *authority_index,
1107                    actual: block_author,
1108                },
1109            ));
1110        }
1111        check_attested_units(protocol_config, transaction, attestation)
1112            .map_err(|e| (NoStoreCheck::Attestation, e))?;
1113        if attestors_cut_off
1114            .get_or_insert_with(|| {
1115                epoch_store.attestors_cut_off_as_of(horizon(protocol_config, commit_index))
1116            })
1117            .contains(authority_index)
1118        {
1119            return Err((
1120                NoStoreCheck::AttestorCutOff,
1121                IotaError::AttestorCutOff {
1122                    attestor: *authority_index,
1123                },
1124            ));
1125        }
1126
1127        // Payload-only gas bounds: a pure function of the transaction and
1128        // epoch constants, so this drop needs no store read. The full gas
1129        // check (owner, coin type, balance) runs with the loaded coins in
1130        // Check #6.
1131        let data = transaction.data().transaction();
1132        check_gas_bounds(
1133            protocol_config,
1134            epoch_store.reference_gas_price(),
1135            data.gas_price(),
1136            data.gas_budget(),
1137        )
1138        .map_err(|e| (NoStoreCheck::GasBounds, e.into()))?;
1139
1140        // Checked last, so a copy that also fails an earlier check, such as
1141        // one from a cut-off attestor, drops for that check.
1142        check_attested_shared_object_versions(transaction, attestation)
1143            .map_err(|e| (NoStoreCheck::Attestation, e))?;
1144    }
1145
1146    // Check #4: Extract owned input objects for lock conflict detection.
1147    extract_owned_input_objects(tx).map_err(|e| (NoStoreCheck::OwnedInputs, e))
1148}

1150/// The outcome of the transaction dependency check at a commit.
1151///
1152/// The horizon of a commit is an earlier commit: its index is the commit's
1153/// index minus the protocol config's horizon distance (see [`horizon`]).
1154/// Before a validator validates a commit, it waits until every root of the
1155/// horizon and of every earlier commit has executed, so the effects of those
1156/// roots exist on every validator. A commit later than the horizon, one with
1157/// a higher index, may not have executed on every validator yet.
1158enum DependencyVerdict {
1159    /// The dependency executed successfully, as a root of the horizon or of
1160    /// an earlier commit.
1161    Satisfied,
1162    /// The dependency is sequenced, but not every validator may know its
1163    /// outcome yet: it was kept earlier in this commit, it is deferred, or it
1164    /// is a root of a commit later than the horizon. At sequencing the
1165    /// dependent is deferred until the dependency is a root, or cancelled past
1166    /// the deferral limit. Once scheduled, it waits in the execution scheduler
1167    /// for the dependency's effects and fails at execution if they report a
1168    /// failure.
1169    Pending,
1170    /// The dependency's effects report a failure, a cancellation at
1171    /// sequencing included, or the dependency was dropped for good earlier in
1172    /// this commit.
1173    Failed,
1174    /// The dependency is not a root of an earlier commit of this epoch, is
1175    /// not deferred, and has not been kept in this commit so far. This
1176    /// includes a dependency of an earlier epoch, which only admission rejects
1177    /// for good.
1178    NotVisibleYet,
1179}
1180
1181/// Decides a transaction dependency at `commit_index` from consensus state
1182/// only: this commit's decisions so far, the deferred set, and the commit
1183/// each root of the epoch belongs to (`root_commits`). It reads the
1184/// dependency's effects only for a root of the horizon or of an earlier
1185/// commit, which every validator has executed. The perpetual store is never
1186/// consulted for a digest that is not a root of this epoch: whether a
1187/// transaction of an earlier epoch is still there depends on each node's
1188/// pruning, so a dependency has to be a root of the current epoch.
1189///
1190/// # Panics
1191///
1192/// Panics if the dependency is a root of the horizon or of an earlier commit
1193/// but has no effects.
1194fn dependency_verdict(
1195    dependency: TransactionDigest,
1196    commit_index: CommitIndex,
1197    decisions: &CommitDecisions,
1198    epoch_store: &Arc<AuthorityPerEpochStore>,
1199    authority_state: &AuthorityState,
1200) -> IotaResult<DependencyVerdict> {
1201    if let Some((decision, _)) = decisions.verdicts.get(&dependency) {
1202        return Ok(match decision {
1203            PostConsensusDecision::Kept => DependencyVerdict::Pending,
1204            PostConsensusDecision::Dropped => DependencyVerdict::Failed,
1205            PostConsensusDecision::DroppedInputNotVisibleYet
1206            | PostConsensusDecision::DroppedCopy => DependencyVerdict::NotVisibleYet,
1207        });
1208    }
1209    // One reloaded from deferral at this commit is decided above, as it is
1210    // validated before its dependent.
1211    if epoch_store.is_deferred_transaction(&dependency) {
1212        return Ok(DependencyVerdict::Pending);
1213    }
1214    let Some(root_commit) = epoch_store.root_commit_of(&dependency)? else {
1215        return Ok(DependencyVerdict::NotVisibleYet);
1216    };
1217    let horizon = horizon(epoch_store.protocol_config(), commit_index);
1218    if root_commit > horizon {
1219        return Ok(DependencyVerdict::Pending);
1220    }
1221    let effects = authority_state
1222        .get_transaction_cache_reader()
1223        .try_get_executed_effects(&dependency)?
1224        .unwrap_or_else(|| {
1225            fatal!(
1226                "transaction {dependency:?} is a root of commit {root_commit}, no later than \
1227                 commit {horizon}, the horizon of commit {commit_index}, but has no effects"
1228            )
1229        });
1230    Ok(if effects.status().is_success() {
1231        DependencyVerdict::Satisfied
1232    } else {
1233        DependencyVerdict::Failed
1234    })
1235}

1237/// The decision so far for each user transaction digest of a commit.
1238#[derive(Default)]
1239struct CommitDecisions {
1240    /// The decision of the last copy of each digest validated, with the error
1241    /// of a drop.
1242    verdicts: HashMap<TransactionDigest, (PostConsensusDecision, Option<IotaError>)>,
1243    /// The digests no later copy can change the decision of: a copy was
1244    /// kept, or dropped for a reason every copy shares.
1245    decided: HashSet<TransactionDigest>,
1246}
1247
1248impl CommitDecisions {
1249    fn is_decided(&self, digest: &TransactionDigest) -> bool {
1250        self.decided.contains(digest)
1251    }
1252
1253    /// Records the decision of `digest`, with the error of a drop.
1254    fn decide(
1255        &mut self,
1256        digest: TransactionDigest,
1257        decision: PostConsensusDecision,
1258        error: Option<IotaError>,
1259    ) {
1260        self.verdicts.insert(digest, (decision, error));
1261        self.decided.insert(digest);
1262    }
1263
1264    /// Records the drop of one copy of `digest` with `error`. `missing` is
1265    /// whether an input was not visible at the horizon. A drop that may come
1266    /// from the copy's own signatures leaves the digest open for a later copy;
1267    /// it is saved as [`PostConsensusDecision::DroppedCopy`] unless an input
1268    /// was not visible, which is not final either.
1269    fn drop_copy(
1270        &mut self,
1271        digest: TransactionDigest,
1272        error: IotaError,
1273        missing: bool,
1274        from_signatures: bool,
1275    ) {
1276        if from_signatures && missing {
1277            self.verdicts.insert(
1278                digest,
1279                (
1280                    PostConsensusDecision::DroppedInputNotVisibleYet,
1281                    Some(error),
1282                ),
1283            );
1284        } else if from_signatures {
1285            self.verdicts
1286                .insert(digest, (PostConsensusDecision::DroppedCopy, Some(error)));
1287        } else if missing {
1288            self.decide(
1289                digest,
1290                PostConsensusDecision::DroppedInputNotVisibleYet,
1291                Some(error),
1292            );
1293        } else {
1294            self.decide(digest, PostConsensusDecision::Dropped, Some(error));
1295        }
1296    }
1297}

1299/// The check a copy of a transaction failed, for
1300/// [`drop_may_come_from_signatures`].
1301enum FailedCheck<'a> {
1302    /// `validity_check`, with its error.
1303    Validity(&'a IotaError),
1304    /// The attestation of this copy: its attestor, its units or its recorded
1305    /// versions.
1306    Attestation,
1307    /// Listing the owned inputs.
1308    OwnedInputs,
1309    /// Another transaction holds a lock on this input.
1310    LockConflict(&'a ObjectReference),
1311    /// The commit-indexed reader dropped this input or did not see it.
1312    Input(&'a InputObjectKind),
1313    /// A check whose outcome is the same for every copy.
1314    Data,
1315    /// Any other check of the inputs, deny rules and gas.
1316    Other,
1317}
1318
1319/// Whether a drop of this copy of a transaction may come from its signatures
1320/// rather than from the transaction data, which every copy of the digest
1321/// shares.
1322///
1323/// Block verification checks every signature against the data, except a Move
1324/// authenticator, which it checks only for the address it claims. So a copy
1325/// without one fails like every other copy, while a faulty validator can put
1326/// in its block a copy with a made-up authenticator that fails here. For a
1327/// copy with a Move authenticator, a drop counts as the data's only when the
1328/// data alone explains it: the data fails its own validity check or has
1329/// expired, its inputs cannot be listed, or the conflicting lock or the
1330/// dropped or unseen input is one the data names, or the package holding a
1331/// signer account's authenticate function is denied. Any other drop of such
1332/// a copy, including the other checks of the inputs, deny rules and gas, may
1333/// come from the authenticator. A failed attestation is the copy's own
1334/// whatever its signatures: a later copy may carry a valid one.
1335fn drop_may_come_from_signatures(
1336    transaction: &SenderSignedTransaction,
1337    check: FailedCheck<'_>,
1338    config: &ProtocolConfig,
1339) -> bool {
1340    if matches!(check, FailedCheck::Attestation) {
1341        return true;
1342    }
1343    if transaction.move_authenticators().is_empty() {
1344        return false;
1345    }
1346    let data = transaction.transaction();
1347    let data_names = |kind: &InputObjectKind| {
1348        data.input_objects()
1349            .is_ok_and(|inputs| inputs.contains(kind))
1350    };
1351    match check {
1352        FailedCheck::Attestation => true,
1353        FailedCheck::Validity(error) => {
1354            !matches!(error, IotaError::TransactionExpired)
1355                && !data.is_system_tx()
1356                && data.validity_check(config).is_ok()
1357        }
1358        FailedCheck::OwnedInputs => data.input_objects().is_ok(),
1359        FailedCheck::LockConflict(obj_ref) => {
1360            !data_names(&InputObjectKind::ImmOrOwnedMoveObject(*obj_ref))
1361        }
1362        FailedCheck::Input(kind) => {
1363            !data_names(kind)
1364                && !matches!(
1365                    kind,
1366                    InputObjectKind::ImmOrOwnedMoveObject(obj_ref)
1367                        if data.receiving_objects().contains(obj_ref)
1368                )
1369        }
1370        FailedCheck::Data => false,
1371        FailedCheck::Other => true,
1372    }
1373}

1375/// Narrows the byte-derived owned inputs of an already-executed transaction to
1376/// the references it consumed — the same set the main path locks — by
1377/// intersecting them with the pre-execution references in its own effects;
1378/// immutable inputs never appear there. A missing effects body
1379/// is a storage error, never a "not executed" verdict, which would drop a
1380/// committee-agreed winner other validators keep.
1381fn filter_locked_inputs_by_effects(
1382    authority_state: &AuthorityState,
1383    digest: &TransactionDigest,
1384    owned_inputs: Vec<ObjectReference>,
1385) -> IotaResult<Vec<ObjectReference>> {
1386    let effects = authority_state
1387        .get_transaction_cache_reader()
1388        .try_get_executed_effects(digest)?
1389        .ok_or_else(|| IotaError::GenericAuthority {
1390            error: format!(
1391                "effects of already-executed transaction {digest:?} are unavailable in \
1392                 post-consensus validation"
1393            ),
1394        })?;
1395    // Owned inputs always appear in effects and immutable ones never do
1396    // (`TemporaryStore::ensure_active_inputs_mutated` force-mutates every
1397    // non-immutable owned input); intersecting on the full `ObjectReference`
1398    // — the lock table's own key — keeps the sets identical by construction.
1399    let consumed: HashSet<ObjectReference> = effects
1400        .old_object_metadata()
1401        .into_iter()
1402        .map(|old| *old.reference())
1403        .collect();
1404    Ok(owned_inputs
1405        .into_iter()
1406        .filter(|obj_ref| consumed.contains(obj_ref))
1407        .collect())
1408}

1410/// Finds an existing owned-object lock on `obj_ref`, walking three tiers in
1411/// order:
1412/// 1. `current_commit_locks` — locks acquired earlier in the same commit.
1413/// 2. Consensus quarantine — locks from previous uncommitted commits.
1414/// 3. Persistent DB — committed locks.
1415///
1416/// Returns `Ok(Some(locker))` if any tier holds a lock, `Ok(None)` if the
1417/// input is free. The caller decides what to do with the result (drop with
1418/// `ObjectLockConflict` for a contender, or `fatal!` if a winner is
1419/// out-locked).
1420fn find_existing_lock(
1421    obj_ref: &ObjectReference,
1422    current_commit_locks: &HashMap<ObjectReference, LockDetails>,
1423    epoch_store: &Arc<AuthorityPerEpochStore>,
1424) -> IotaResult<Option<LockDetails>> {
1425    if let Some(&locker) = current_commit_locks.get(obj_ref) {
1426        return Ok(Some(locker));
1427    }
1428    if let Some(locker) = epoch_store.get_quarantined_owned_object_lock(obj_ref) {
1429        return Ok(Some(locker));
1430    }
1431    epoch_store.tables()?.get_locked_transaction(obj_ref)
1432}

1434/// Extracts the `ImmOrOwnedMoveObject` input references of a
1435/// `UserTransactionV1` consensus transaction (excludes shared objects and
1436/// packages).
1437///
1438/// This is the set probed for lock conflicts, not the set that gets locked.
1439/// It is derived from the transaction bytes alone, where owned and immutable
1440/// inputs share one kind, so it cannot tell them apart; the callers that
1441/// acquire locks narrow it down first. Probing immutable references is
1442/// harmless, since no tier ever holds a lock on one.
1443fn extract_owned_input_objects(
1444    tx: &VerifiedSequencedConsensusTransaction,
1445) -> IotaResult<Vec<ObjectReference>> {
1446    let Some(transaction_data) = (match &tx.0.transaction {
1447        SequencedConsensusTransactionKind::External(ext) => {
1448            ext.kind.as_user_transaction().map(|t| t.data())
1449        }
1450        SequencedConsensusTransactionKind::System(_) => None,
1451    }) else {
1452        return Err(IotaError::GenericAuthority {
1453            error: "Expected UserTransactionV1 in extract_owned_input_objects".to_string(),
1454        });
1455    };
1456
1457    // Use SenderSignedTransaction::input_objects() rather than
1458    // Transaction::input_objects() to also include objects coming from
1459    // MoveAuthenticator signatures. Those can only be immutable or shared,
1460    // so they widen the probe set but never the locked set. Packages are left
1461    // out below anyway.
1462    let owned_objects = transaction_data
1463        .input_objects(false)?
1464        .into_iter()
1465        .filter_map(|input| match input {
1466            InputObjectKind::ImmOrOwnedMoveObject(obj_ref) => Some(obj_ref),
1467            InputObjectKind::SharedMoveObject { .. } => None,
1468            InputObjectKind::MovePackage(_) => None,
1469        })
1470        .collect();
1471
1472    Ok(owned_objects)
1473}
