4//! Post-consensus validation and owned-object conflict resolution for
5//! `UserTransactionV1` transactions.
6//!
7//! This module merges two formerly separate pipeline stages into a single pass:
8//!
9//! 1. **Semantic validation** — deduplication, already-executed check, structural validity,
10//!    attestation checks, and deny checks (deny lists, gas, ownership, coin deny list, Move
11//!    authenticator).
12//! 2. **Owned-object conflict resolution** (white-flag) — three-tier lock check and lock
13//!    acquisition.
14//!
15//! Processing both in one loop avoids iterating over every transaction twice.
16//! A transaction that can't acquire its object locks is dropped before the
17//! expensive validation. With more than one reader its inputs may have been
18//! read ahead of the loop, and that result is then left unused.
19//!
20//! # Per-transaction order within the loop
21//!
22//! 1. Non-`UserTransactionV1` — pass through unchanged.
23//! 2. Dedup by `ConsensusTransactionKey` — silent drop. A later copy of a user transaction with
24//!    other signatures or another attestation is validated when every earlier copy was dropped for
25//!    a reason that may come from its own signatures or attestation (see
26//!    `drop_may_come_from_signatures`).
27//! 3. Saved decisions, already-executed and deferred transactions:
28//!    - Replayed commit: a commit replayed after a restart repeats the decisions saved on its first
29//!      run. A saved drop is repeated without checks. Once the switch to executing synced
30//!      checkpoints after commit `L` is saved, a commit at or below `L` repeats a saved keep
31//!      without checks and takes no locks for it. Otherwise a saved keep is validated again unless
32//!      the transaction has executed or was deferred at an earlier commit.
33//!    - Already executed (typically by state sync): the transaction is **retained** as a
34//!      committee-agreed winner, not dropped: dropping it would make this validator's checkpoints
35//!      differ from those of the other validators. It registers the locks its own effects report
36//!      and skips re-validation. This applies only if the first run of this commit saved a keep for
37//!      it; otherwise it goes through the checks below like any other transaction, unless it was
38//!      deferred.
39//!    - Deferred at an earlier commit: the transaction is kept without checks and takes no new
40//!      locks. It was validated at the commit that kept it and still holds the locks it took there.
41//! 4. `validity_check()` — drop with error.
42//! 5. Attestation checks (attested transactions only): the attestor is the block author, the
43//!    attested units are within bounds, the attestor is not cut off as of the horizon, and the gas
44//!    price and budget are within bounds — drop with error. The attestation is the copy's own, so a
45//!    later copy of the digest is validated.
46//! 6. Three-tier lock conflict check (local HashMap → quarantine → DB) — drop with error, except a
47//!    lock held by the same transaction, which is exempt. Cheap; performed before expensive checks.
48//! 7. `handle_transaction_validation_checks_at_commit()` — drop with error. An attested transaction
49//!    runs the input checks execution runs, gas included, and the checks on receiving objects; the
50//!    publish verifier stays at execution. Only reached when all locks are free. Its result may
51//!    have been computed ahead of the loop, see `ReadAhead`.
52//! 8. All passed — acquire locks in the local tracking map, keep transaction.
53//!
54//! Non-`UserTransactionV1` transactions pass through unchanged.
55//!
56//! # Which references get locked
57//!
58//! Step 6 probes every `ImmOrOwnedMoveObject` reference, but only genuinely
59//! owned references are locked — an immutable input never takes a new
60//! version, so its lock would hold until the epoch ends. Step 8 filters via
61//! the loaded objects, step 3 via the executed transaction's effects.
62

115/// The post-consensus validation decision for one transaction at one
116/// consensus commit.
117///
118/// Saved in the epoch tables, so its encoding must stay readable by other
119/// binaries within the epoch: variants carry no data and new ones go at the
120/// end.
121#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
122pub enum PostConsensusDecision {
123    /// The transaction stayed in the commit.
124    Kept,
125    /// The transaction was dropped.
126    Dropped,
127    /// The transaction was dropped because an input is not visible at the
128    /// commit's [horizon](crate::post_consensus_input_reader::reader::horizon)
129    /// yet. The digest can be kept when sequenced again, so the drop is not
130    /// its final status.
131    DroppedInputNotVisibleYet,
132    /// The copy of the transaction validated last was dropped for a reason
133    /// that may come from its own signatures, which other copies of the
134    /// digest do not share. Another copy can be kept when sequenced, so the
135    /// drop is not the final status of the digest.
136    DroppedCopy,
137}
138
139/// A post-consensus validation decision as saved, so a replay of the commit
140/// after a restart reaches the same decision.
141///
142/// The error of a drop is kept as BCS bytes and decoded on its own, so a
143/// binary that encodes `IotaError` differently still reads the decision.
144#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
145pub(crate) struct SavedPostConsensusDecision {
146    pub(crate) decision: PostConsensusDecision,
147    /// The BCS bytes of the drop's error; empty for a keep.
148    pub(crate) error: Vec<u8>,
149}
150
151impl SavedPostConsensusDecision {
152    pub(crate) fn kept() -> Self {
153        Self {
154            decision: PostConsensusDecision::Kept,
155            error: Vec::new(),
156        }
157    }
158
159    pub(crate) fn dropped(decision: PostConsensusDecision, error: &IotaError) -> Self {
160        Self {
161            decision,
162            error: bcs::to_bytes(error).expect("an IotaError should encode to BCS"),
163        }
164    }
165
166    /// The error of a saved drop, or `IotaError::Unknown` if this binary
167    /// cannot decode it.
168    pub(crate) fn error(&self) -> IotaError {
169        bcs::from_bytes(&self.error).unwrap_or_else(|e| {
170            IotaError::Unknown(format!(
171                "the saved error of a post-consensus drop cannot be decoded: {e}"
172            ))
173        })
174    }
175}

185/// Validates `UserTransactionV1` transactions and resolves owned-object
186/// conflicts in a single pass.
187///
188/// For each `UserTransactionV1` in consensus order:
189/// - Runs deduplication, structural validity, lock conflict check, and deny checks (deny list, gas,
190///   ownership, coin deny list, Move authenticator).
191/// - If all checks pass, acquires owned-object locks in a local tracking map; immutable inputs are
192///   not locked, as an immutable input never takes a new version and its lock would hold until the
193///   epoch ends.
194/// - Drops the transaction (with an error) on any failure.
195/// - An already-executed transaction is **retained** (not dropped): it registers the locks its
196///   effects report and skips re-validation. Dropping it would make this validator's checkpoints
197///   differ from those of the other validators.
198/// - A transaction in `previously_deferred` is kept without checks and takes no new locks: the
199///   locks it took at the commit that kept it stay in place.
200///
201/// Copies of one digest with other signatures can come from different authors in one commit. The
202/// first copy is validated; a later one only while every earlier copy was dropped for a reason that
203/// may come from its own signatures. The digest's decision is that of the last copy validated, and
204/// only a kept copy stays in `transactions`.
205///
206/// Called only with the P-COOL flow on; the caller checks the flag.
207///
208/// The decision for every candidate is saved before returning, including keeps that the caller
209/// then defers, and a commit replayed after a restart repeats the saved decisions; step 3 of the
210/// module docs says which transactions are validated again. Panics if the saved decisions are
211/// incomplete, the candidates differ from the saved ones, or a saved keep is now dropped. Once the
212/// switch to executing synced checkpoints after commit `L` is saved, also panics for a commit
213/// above `L`, or for a commit at or below `L` without saved decisions.
214///
215/// Non-`UserTransactionV1` transactions pass through unchanged.
216///
217/// # Arguments
218///
219/// * `authority_state` — Used for cache reads and deny checks.
220/// * `epoch_store` — Current epoch store (protocol config, lock storage, governance deny rules).
221/// * `commit_index` — The consensus commit being validated. Inputs are read as of this commit.
222/// * `previously_deferred` — The transactions deferred at earlier commits and reloaded into
223///   `transactions`, randomness-using ones included.
224/// * `transactions` — All sequenced transactions for this consensus commit; modified in-place.
225///
226/// # Returns
227///
228/// `Ok((dropped, locks, all_user_tx_digests))` where:
229/// - `dropped` — `(digest, error, decision)` for every semantically-invalid or lock-conflicting
230///   transaction, where `decision` is never `Kept`. Silent drops (duplicates) are **not** included.
231/// - `locks` — Owned-object locks acquired in this commit, to be stored in the consensus quarantine
232///   so subsequent commits can see them.
233/// - `all_user_tx_digests` — Every `UserTransactionV1` digest that passed dedup (both kept and
234///   dropped), once each. Used by the caller to release pre-consensus soft locks.
235pub async fn validate_and_resolve_conflicts(
236    authority_state: &AuthorityState,
237    epoch_store: &Arc<AuthorityPerEpochStore>,
238    commit_index: CommitIndex,
239    previously_deferred: &PreviouslyDeferredTransactions,
240    transactions: &mut Vec<VerifiedSequencedConsensusTransaction>,
241) -> IotaResult<(
242    Vec<(TransactionDigest, IotaError, PostConsensusDecision)>,
243    HashMap<ObjectReference, LockDetails>,
244    Vec<TransactionDigest>,
245)> {
246    // Keys of the transactions other than user transactions seen so far.
247    let mut seen_keys: HashSet<SequencedConsensusTransactionKey> = HashSet::new();
248    // The copies of each digest validated at this commit, in consensus order.
249    let mut validated_copies: HashMap<TransactionDigest, Vec<ValidatedCopy<'_>>> = HashMap::new();
250    let mut decisions = CommitDecisions::default();
251    // Every validated copy's digest, in consensus order: a digest appears once
252    // per copy validated.
253    let mut candidates = Vec::with_capacity(transactions.len());
254    // Locks acquired within this commit. Populated for every transaction that
255    // passes all checks; used by subsequent transactions' conflict checks.
256    let mut current_commit_locks: HashMap<ObjectReference, LockDetails> = HashMap::new();
257    // Index-parallel keep flags: true = keep, false = remove.
258    let mut keep = vec![true; transactions.len()];
259    // All UserTransactionV1 digests seen in this commit (both kept and dropped),
260    // used by the caller to release pre-consensus soft locks.
261    let mut all_user_tx_digests = Vec::with_capacity(transactions.len());
262
263    // One deny-rule snapshot for the whole commit, so every transaction in it
264    // is judged by the same set. This must be the consensus-derived set — local
265    // config can differ between validators and would fork the post-consensus
266    // decisions.
267    let governance_deny_rules = epoch_store.get_active_transaction_deny_rules();
268    let deny_config: &dyn DenyRuleConfig = governance_deny_rules.as_ref();
269
270    // The decisions saved when this commit was first validated, present only
271    // when it is replayed after a restart. A saved candidate list means every
272    // candidate has a saved decision.
273    let saved_candidates = epoch_store
274        .tables()?
275        .post_consensus_decision_candidates
276        .get(&commit_index)?;
277    // A node that switched to executing synced checkpoints after commit
278    // `last` replays only the commits up to it after a restart. Synced
279    // checkpoints have since written outputs without handler rows, which the
280    // reader cannot place, so these commits repeat their saved decisions.
281    let replaying_up_to_the_switch =
282        match epoch_store.last_commit_before_synced_checkpoint_execution()? {
283            Some(last) if commit_index > last => fatal!(
284                "commit {commit_index} validated after the switch to synced checkpoints \
285                 after commit {last}"
286            ),
287            Some(last) if saved_candidates.is_none() => fatal!(
288                "commit {commit_index} has no saved decisions although the switch to synced \
289                 checkpoints after commit {last} saved every decision up to it"
290            ),
291            Some(_) => true,
292            None => false,
293        };
294    // How many copies of each digest the first run validated. The decision
295    // of the last one is the digest's; the ones before it were dropped for
296    // their own signatures.
297    let mut saved_copies: HashMap<TransactionDigest, usize> = HashMap::new();
298    for digest in saved_candidates.iter().flatten() {
299        *saved_copies.entry(*digest).or_default() += 1;
300    }
301    let mut saved_decisions = HashMap::new();
302
303    // One reader for the whole commit, so every transaction in it is read as
304    // of the same commit index.
305    let reader = Arc::new(CommitIndexedReader::new(
306        authority_state.get_object_cache_reader().clone(),
307        epoch_store.clone(),
308        commit_index,
309    ));
310    // The attestors cut off as of this commit's horizon, read at the first
311    // attested transaction.
312    let mut attestors_cut_off: Option<BTreeSet<u8>> = None;
313
314    // The results of Check #6 read ahead of the loop, by position in
315    // `transactions`. A replayed commit reads nothing ahead: the inputs of
316    // a transaction it repeats a saved decision for may have left the store.
317    let readers = authority_state
318        .config
319        .post_consensus_validation_readers
320        .map_or_else(default_validation_readers, NonZeroUsize::get);
321    let mut read_ahead = if readers > 1 && saved_candidates.is_none() {
322        let _scope = monitored_scope("PostConsensusValidation::ReadAhead");
323        ReadAhead::new(
324            epoch_store,
325            commit_index,
326            previously_deferred,
327            transactions,
328            &mut attestors_cut_off,
329        )
330        .run(
331            authority_state,
332            epoch_store,
333            &reader,
334            &governance_deny_rules,
335            readers,
336        )
337        .await
338    } else {
339        HashMap::new()
340    };
341    let input_reads = &authority_state
342        .metrics
343        .consensus_handler_validation_input_reads;
344    let _scope = monitored_scope("PostConsensusValidation::Decide");
345
346    for (i, tx) in transactions.iter().enumerate() {
347        // Only validate UserTransactionV1; pass everything else through
348        // unchanged, once per key.
349        let Some((transaction, attestation)) = (match &tx.0.transaction {
350            SequencedConsensusTransactionKind::External(ext) => {
351                ext.kind.as_user_transaction_with_attestation()
352            }
353            SequencedConsensusTransactionKind::System(_) => None,
354        }) else {
355            if !seen_keys.insert(tx.0.key()) {
356                keep[i] = false;
357            }
358            continue;
359        };
360
361        let digest = *transaction.digest();
362        let signatures = transaction.data().signatures();
363
364        // Check #0: Dedup by digest.
365        // The same UserTransactionV1 may appear in DAG blocks from multiple
366        // validators within the same consensus commit. Silent drop — not added
367        // to `dropped`. A copy with other signatures or another attestation
368        // is validated while no earlier copy has decided the digest. A copy
369        // with the same signatures, attestation and, if attested, block
370        // author as one already validated would get the same decision.
371        let copy = (
372            signatures,
373            attestation.map(|attestation| (attestation, tx.0.certificate_author_index)),
374        );
375        let copies = validated_copies.entry(digest).or_default();
376        if copies.is_empty() {
377            all_user_tx_digests.push(digest);
378        } else if decisions.is_decided(&digest) || copies.contains(&copy) {
379            keep[i] = false;
380            continue;
381        }
382        copies.push(copy);
383        let copy_number = copies.len();
384        candidates.push(digest);
385
386        let saved = match &saved_candidates {
387            Some(_) => {
388                if copy_number < saved_copies.get(&digest).copied().unwrap_or_default() {
389                    keep[i] = false;
390                    continue;
391                }
392                match epoch_store.post_consensus_decision(commit_index, digest)? {
393                    Some(saved) => Some(saved),
394                    None => fatal!(
395                        "commit {commit_index} has a saved candidate list but no saved \
396                         validation decision for {digest:?}"
397                    ),
398                }
399            }
400            None => None,
401        };
402        let saved_decision = saved.as_ref().map(|saved| saved.decision);
403        if let Some(decision) = saved_decision {
404            saved_decisions.insert(digest, decision);
405        }
406        // A saved drop is replayed as is: the inputs it was decided on may
407        // have changed since.
408        if let Some(saved) = saved.filter(|saved| saved.decision != PostConsensusDecision::Kept) {
409            decisions.decide(digest, saved.decision, Some(saved.error()));
410            keep[i] = false;
411            continue;
412        }
413        // Its locks are not registered: nothing in this epoch reads them, as
414        // every transaction up to the switch repeats its saved decision and no
415        // commit after it is validated.
416        if replaying_up_to_the_switch && saved_decision == Some(PostConsensusDecision::Kept) {
417            debug!(
418                ?digest,
419                "Repeating the saved keep up to the synced checkpoint switch"
420            );
421            decisions.decide(digest, PostConsensusDecision::Kept, None);
422            continue;
423        }
424        // Validating it again could drop it, and the locks it took at the
425        // commit that kept it would then stay until the epoch ends. Later
426        // contenders find those locks in the quarantine or the lock table.
427        if previously_deferred.contains_key(&digest) {
428            debug!(
429                ?digest,
430                "Keeping a transaction deferred at an earlier commit without validating it again"
431            );
432            decisions.decide(digest, PostConsensusDecision::Kept, None);
433            continue;
434        }
435        // Whether a drop of this copy may come from its own signatures, so a
436        // later copy of the digest is validated.
437        let from_signatures = |check: FailedCheck<'_>| {
438            drop_may_come_from_signatures(transaction.data(), check, epoch_store.protocol_config())
439        };
440
441        // Check #1: Already executed (typically by state-sync before this node's
442        // consensus handler reached the commit). It is a committee-agreed winner, so
443        // keep it in the sequence to flow into checkpoint roots like on every other
444        // validator (dropping it would make this validator's checkpoint differ from
445        // those of the others). Register its owned-object locks so double-spend
446        // siblings still lose, then skip re-validation (#2/#5);
447        // the active scheduler's enqueue filter suppresses the re-execution.
448        //
449        // Effects alone do not show at which commit the transaction was kept,
450        // so only a saved keep at this commit skips validation; its consumed
451        // inputs may have left the live state by now. Without one, the
452        // commit-indexed reader decides, as on every other validator.
453        if saved_decision == Some(PostConsensusDecision::Kept)
454            && authority_state
455                .get_transaction_cache_reader()
456                .try_is_tx_already_executed(&digest)?
457        {
458            // Byte-based, so safe even though the inputs are already consumed.
459            let owned_inputs = filter_locked_inputs_by_effects(
460                authority_state,
461                &digest,
462                extract_owned_input_objects(tx)?,
463            )?;
464            for obj_ref in &owned_inputs {
465                // A winner cannot be out-locked: after the effects filter,
466                // every reference here was consumed by this transaction, so a
467                // lock held by a different tx is a consistency violation, not
468                // a conflict. (Flag off, immutable references, which are not
469                // consumed, stay in the set and weaken this invariant.)
470                if let Some(other) =
471                    find_existing_lock(obj_ref, &current_commit_locks, epoch_store)?
472                {
473                    if other != digest {
474                        fatal!(
475                            "already-executed transaction {:?} has owned input {:?} \
476                             locked by a different transaction {:?}",
477                            digest,
478                            obj_ref,
479                            other,
480                        );
481                    }
482                }
483                current_commit_locks.insert(*obj_ref, digest);
484            }
485            debug!(
486                ?digest,
487                num_owned_inputs = owned_inputs.len(),
488                "Transaction already executed; retained as checkpoint root, skipping re-validation"
489            );
490            // keep[i] stays true so the transaction remains in the sequence.
491            decisions.decide(digest, PostConsensusDecision::Kept, None);
492            continue;
493        }
494
495        // Checks #2 to #4 read no store. `ReadAhead::new` picks the
496        // transactions to read ahead with the same function.
497        let owned_inputs = match checks_reading_no_store(
498            epoch_store,
499            commit_index,
500            tx,
501            transaction,
502            attestation,
503            &mut attestors_cut_off,
504        ) {
505            Ok(owned_inputs) => owned_inputs,
506            Err((check, e)) => {
507                if check == NoStoreCheck::AttestorCutOff {
508                    // Every transaction in a cut-off attestor's blocks drops
509                    // here: debug, not warn.
510                    debug!(
511                        ?digest,
512                        commit_index,
513                        error = ?e,
514                        "attestor cut off for the rest of the epoch, dropping"
515                    );
516                    authority_state
517                        .metrics
518                        .consensus_handler_validation_attestor_cut_off_transactions
519                        .inc();
520                } else {
521                    warn!(
522                        ?digest,
523                        commit_index,
524                        attested = attestation.is_some(),
525                        ?check,
526                        error = ?e,
527                        "user transaction failed a post-consensus check that reads no store, dropping"
528                    );
529                }
530                let from_signatures = from_signatures(match check {
531                    NoStoreCheck::Validity => FailedCheck::Validity(&e),
532                    NoStoreCheck::Attestation | NoStoreCheck::AttestorCutOff => {
533                        FailedCheck::Attestation
534                    }
535                    NoStoreCheck::GasBounds => FailedCheck::Data,
536                    NoStoreCheck::OwnedInputs => FailedCheck::OwnedInputs,
537                });
538                decisions.drop_copy(digest, e, false, from_signatures);
539                keep[i] = false;
540                continue;
541            }
542        };
543
544        // Check #5: Three-tier lock conflict check.
545        // Cheap (HashMap + quarantine + DB lookups); performed before the
546        // deny checks so a conflicting transaction is dropped without them.
547        // Its inputs may have been read ahead all the same.
548        //
549        // Locks are keyed by full ObjectReference (id + version + digest), not just
550        // ObjectID. Two transactions referencing the same object at different
551        // versions will NOT conflict here — version freshness is checked in
552        // Check #6, where the commit-indexed reader rejects an input whose
553        // version is not live at the commit.
554        //
555        // Probing the raw set is safe though immutable inputs are never
556        // locked: acquisition never inserts one, and the lock tables are
557        // epoch-scoped while the protocol config is fixed per epoch, so no
558        // tier can hold a stale immutable lock.
559        //
560        // Tier 1: Local HashMap (current commit).
561        // Tier 2: Consensus quarantine (previous uncommitted commits).
562        // Tier 3: Persistent DB (committed data).
563        let mut conflict: Option<(ObjectReference, IotaError)> = None;
564        for obj_ref in &owned_inputs {
565            if let Some(locked_by) =
566                find_existing_lock(obj_ref, &current_commit_locks, epoch_store)?
567            {
568                // A lock held by this same transaction is its own lock from an
569                // earlier commit, not a conflict; Check #1 accepts one too.
570                // Same-commit duplicates cannot slip through here, since Check #0
571                // lets a later copy through only while no copy of the digest is
572                // kept.
573                if locked_by == digest {
574                    continue;
575                }
576
577                debug!(
578                    ?digest,
579                    ?obj_ref,
580                    ?locked_by,
581                    "Transaction conflicts with existing owned-object lock, dropping"
582                );
583                conflict = Some((
584                    *obj_ref,
585                    IotaError::ObjectLockConflict {
586                        obj_ref: *obj_ref,
587                        pending_transaction: locked_by,
588                    },
589                ));
590                break;
591            }
592        }
593        if let Some((obj_ref, e)) = conflict {
594            decisions.drop_copy(
595                digest,
596                e,
597                false,
598                from_signatures(FailedCheck::LockConflict(&obj_ref)),
599            );
600            keep[i] = false;
601            continue;
602        }
603
604        // Check #6: Validation and deny checks. Only reached when all locks are
605        // free. With one reader that skips the object loading for a
606        // transaction the lock conflict check drops. With more, its inputs
607        // were read ahead and the result is left unused.
608        //
609        // Safe to skip signature re-verification: the consensus block verifier
610        // (`IotaTxValidator::validate_transactions`) already called
611        // `verify_tx()` on every `UserTransactionV1` before accepting the
612        // block. Re-verifying here would not add safety — if a quorum
613        // committed a bad signature it indicates a protocol-level failure
614        // (2f+1 Byzantine/buggy validators), not something we can recover from
615        // by rejecting the transaction post-consensus. Doing so would also risk
616        // diverging from other honest validators.
617        //
618        // The result depends only on this copy and the state as of the
619        // horizon, never on the transactions before it in the commit, so one
620        // read ahead of the loop is the one a read here would give.
621        let checked = match read_ahead.remove(&i) {
622            Some(checked) => {
623                input_reads.with_label_values(&["ahead"]).inc();
624                checked
625            }
626            None => {
627                input_reads.with_label_values(&["inline"]).inc();
628                authority_state.handle_transaction_validation_checks_at_commit(
629                    &reader,
630                    &VerifiedTransaction::new_from_verified((*transaction).clone()),
631                    epoch_store,
632                    deny_config,
633                    VerifierLimitsSource::ProtocolConfig,
634                    attestation.is_some(),
635                )
636            }
637        };
638        // The input the reader dropped or did not see, and whether it did
639        // not see it.
640        let mut input_verdict: Option<(InputObjectKind, bool)> = None;
641        let mut denied_for_every_copy = false;
642        // Inputs read as of the commit. A missing input is reported with
643        // the error admission gives a missing input, which the transaction
644        // and quorum drivers retry: it drops the transaction from this
645        // commit only, the decision is saved as `Missing`, and a
646        // resubmission can be kept at a later commit. A dropped input is
647        // final for the digest, so it has its own error, which the drivers
648        // do not retry (a drop that may come from the copy's signatures is
649        // not sent to the waiters). The reason goes to the log. The Move
650        // authenticator runs at execution instead. Here only whether each
651        // account is one is checked, and its authenticator function field
652        // is read for the deny check of its package, both as of the
653        // horizon. The coin deny list is read as of the horizon too. An
654        // attested transaction runs the input checks execution runs, gas
655        // included, and the checks on receiving objects; the publish
656        // verifier stays at execution.
657        let checked = checked.and_then(|verdict| {
658            let verdicts = &authority_state
659                .metrics
660                .consensus_handler_validation_reader_verdicts;
661            match verdict {
662                ValidationAtCommit::Keep(owned) => {
663                    verdicts.with_label_values(&["keep", "none"]).inc();
664                    Ok(owned)
665                }
666                ValidationAtCommit::Drop(kind, reason) => {
667                    verdicts
668                        .with_label_values(&["drop", &format!("{:?}", reason.kind())])
669                        .inc();
670                    warn!(
671                        ?digest,
672                        commit_index,
673                        ?kind,
674                        ?reason,
675                        "input dropped by the commit-indexed reader"
676                    );
677                    input_verdict = Some((kind, false));
678                    Err(kind.not_available_at_commit_error().into())
679                }
680                ValidationAtCommit::Missing(kind, reason) => {
681                    verdicts
682                        .with_label_values(&["missing", &format!("{:?}", reason.kind())])
683                        .inc();
684                    warn!(
685                        ?digest,
686                        commit_index,
687                        ?kind,
688                        ?reason,
689                        "input not visible at this commit"
690                    );
691                    input_verdict = Some((kind, true));
692                    Err(kind.object_not_found_error().into())
693                }
694                ValidationAtCommit::AuthenticatorPackageDenied(error) => {
695                    denied_for_every_copy = true;
696                    Err(error)
697                }
698            }
699        });
700        let validated_owned_objects = match checked {
701            Ok(owned) => owned,
702            Err(e) => {
703                if e.is_storage_or_epoch_error() {
704                    return Err(e);
705                }
706                warn!(
707                    ?digest,
708                    commit_index,
709                    error = ?e,
710                    "UserTransactionV1 failed post-consensus deny checks, dropping"
711                );
712                let (missing, check) = match &input_verdict {
713                    Some((kind, missing)) => (*missing, FailedCheck::Input(kind)),
714                    None if denied_for_every_copy => (false, FailedCheck::Data),
715                    None => (false, FailedCheck::Other),
716                };
717                let from_signatures = from_signatures(check);
718                decisions.drop_copy(digest, e, missing, from_signatures);
719                keep[i] = false;
720                continue;
721            }
722        };
723
724        // All checks passed — acquire owned-object locks in local tracking.
725        // The validated set comes from loaded objects, so unlike the
726        // byte-derived `owned_inputs` it excludes immutable inputs, which must
727        // never be locked (see the module docs). It is a subset of `owned_inputs`,
728        // so every reference locked here was probed by Check #4 first.
729        for obj_ref in &validated_owned_objects {
730            current_commit_locks.insert(*obj_ref, digest);
731        }
732        // Log the acquired refs, not just their count, so the winner's locks
733        // are attributable per (object_id, version).
734        debug!(
735            ?digest,
736            num_owned_inputs = validated_owned_objects.len(),
737            owned_inputs = ?validated_owned_objects,
738            "Transaction passed post-consensus validation, acquired all object locks"
739        );
740        if attestation.is_some() {
741            authority_state
742                .metrics
743                .consensus_handler_validation_attested_transactions
744                .with_label_values(&["authority"])
745                .inc();
746        }
747        decisions.decide(digest, PostConsensusDecision::Kept, None);
748    }
749    // A result the loop did not take belongs to a transaction it dropped
750    // before Check #6. Its error, if any, is not this commit's.
751    input_reads
752        .with_label_values(&["unused"])
753        .inc_by(read_ahead.len() as u64);
754
755    let dropped: Vec<(TransactionDigest, IotaError, PostConsensusDecision)> = all_user_tx_digests
756        .iter()
757        .filter_map(|digest| match decisions.verdicts.get(digest) {
758            Some((decision, Some(error))) => Some((*digest, error.clone(), *decision)),
759            _ => None,
760        })
761        .collect();
762
763    match &saved_candidates {
764        Some(saved_candidates) => {
765            if *saved_candidates != candidates {
766                fatal!(
767                    "validation candidates of commit {commit_index} differ from the saved \
768                     ones: saved {saved_candidates:?}, now {candidates:?}"
769                );
770            }
771            for digest in &all_user_tx_digests {
772                let decision = decisions.verdicts.get(digest).map(|(decision, _)| decision);
773                let saved = saved_decisions.get(digest);
774                if saved != decision {
775                    fatal!(
776                        "validation decision for {digest:?} at commit {commit_index} \
777                         differs from the saved one: saved {saved:?}, now {decision:?}"
778                    );
779                }
780            }
781        }
782        None => {
783            // Every copy's entry carries the digest's decision.
784            let saved: Vec<_> = candidates
785                .iter()
786                .map(|digest| {
787                    let saved = match decisions
788                        .verdicts
789                        .get(digest)
790                        .expect("every validated copy decides its digest")
791                    {
792                        (decision, Some(error)) => {
793                            SavedPostConsensusDecision::dropped(*decision, error)
794                        }
795                        (_, None) => SavedPostConsensusDecision::kept(),
796                    };
797                    (*digest, saved)
798                })
799                .collect();
800            epoch_store.persist_post_consensus_decisions(commit_index, &saved)?;
801            if !saved.is_empty() {
802                fail_point!("crash-after-post-consensus-decisions");
803            }
804        }
805    }
806
807    if !dropped.is_empty() {
808        warn!(
809            num_dropped = dropped.len(),
810            num_retained = transactions
811                .iter()
812                .enumerate()
813                .filter(|(i, _)| keep[*i])
814                .count(),
815            "Post-consensus validation dropped transactions"
816        );
817    }
818
819    // Remove invalid/duplicate/conflicting entries using the parallel keep
820    // flags.
821    let mut iter = keep.into_iter();
822    transactions.retain(|_| iter.next().unwrap_or(true));
823
824    Ok((dropped, current_commit_locks, all_user_tx_digests))
825}

827/// How many readers validate a commit when the node config sets no number.
828fn default_validation_readers() -> usize {
829    static READERS: OnceLock<usize> = OnceLock::new();
830    *READERS.get_or_init(|| {
831        // Not from the host's cores, so a seed replays the same on every
832        // machine.
833        if cfg!(msim) {
834            4
835        } else {
836            validation_readers_for(
837                std::thread::available_parallelism().map_or(1, NonZeroUsize::get),
838            )
839        }
840    })
841}

848/// The transactions of a commit whose Check #6 runs ahead of the validation
849/// loop. The readers take them one at a time.
850struct ReadAhead {
851    /// The position in the commit, the copy to check and whether it is
852    /// attested.
853    transactions: Vec<(usize, VerifiedTransaction, bool)>,
854    /// The next of `transactions` no reader has taken.
855    next: AtomicUsize,
856}
857
858impl ReadAhead {
859    /// Picks the transactions the loop is expected to take to Check #6: the
860    /// first copy of a digest that passes Checks #2 to #4, not deferred at an
861    /// earlier commit. The loop still runs every check itself, so a
862    /// transaction picked here that it drops earlier, as the loser of an
863    /// owned input is, costs only the reads. `attestors_cut_off` is the
864    /// loop's, filled here when an attested copy gets that far.
865    fn new(
866        epoch_store: &AuthorityPerEpochStore,
867        commit_index: CommitIndex,
868        previously_deferred: &PreviouslyDeferredTransactions,
869        transactions: &[VerifiedSequencedConsensusTransaction],
870        attestors_cut_off: &mut Option<BTreeSet<u8>>,
871    ) -> Self {
872        let mut digests = HashSet::new();
873        let mut picked = Vec::new();
874        for (i, tx) in transactions.iter().enumerate() {
875            let Some((transaction, attestation)) = (match &tx.0.transaction {
876                SequencedConsensusTransactionKind::External(ext) => {
877                    ext.kind.as_user_transaction_with_attestation()
878                }
879                SequencedConsensusTransactionKind::System(_) => None,
880            }) else {
881                continue;
882            };
883            let digest = *transaction.digest();
884            if digests.contains(&digest) || previously_deferred.contains_key(&digest) {
885                continue;
886            }
887            if checks_reading_no_store(
888                epoch_store,
889                commit_index,
890                tx,
891                transaction,
892                attestation,
893                attestors_cut_off,
894            )
895            .is_err()
896            {
897                continue;
898            }
899            // Only now, so a later copy is picked when this one failed.
900            digests.insert(digest);
901            picked.push((
902                i,
903                VerifiedTransaction::new_from_verified((*transaction).clone()),
904                attestation.is_some(),
905            ));
906        }
907        Self {
908            transactions: picked,
909            next: AtomicUsize::new(0),
910        }
911    }
912
913    /// Runs Check #6 for the picked transactions on up to `readers` threads,
914    /// this one included, and returns each result by the transaction's
915    /// position in the commit. A transaction without a result is read by the
916    /// loop.
917    async fn run(
918        self,
919        authority_state: &AuthorityState,
920        epoch_store: &Arc<AuthorityPerEpochStore>,
921        reader: &Arc<CommitIndexedReader>,
922        deny_rules: &Arc<DenyRuleSet>,
923        readers: usize,
924    ) -> HashMap<usize, IotaResult<ValidationAtCommit>> {
925        let this = Arc::new(self);
926        let others: Vec<_> = (1..readers.min(this.transactions.len()))
927            .map(|_| {
928                let this = this.clone();
929                let authority_state = authority_state.shared();
930                let epoch_store = epoch_store.clone();
931                let reader = reader.clone();
932                let deny_rules = deny_rules.clone();
933                let started = Arc::new(AtomicBool::new(false));
934                let handle = tokio::task::spawn_blocking({
935                    let started = started.clone();
936                    move || {
937                        // Set before the first transaction is taken.
938                        started.store(true, Ordering::SeqCst);
939                        this.read(&authority_state, &epoch_store, &reader, deny_rules.as_ref())
940                    }
941                });
942                (started, handle)
943            })
944            .collect();
945        let mut results: HashMap<_, _> = this
946            .read(authority_state, epoch_store, reader, deny_rules.as_ref())
947            .into_iter()
948            .collect();
949        // Every transaction is taken by now, so a reader that has not started
950        // took none and would find none. Its handle completes only once a
951        // thread of the blocking pool is free, so the commit does not await
952        // it.
953        for (started, other) in others {
954            if !started.load(Ordering::SeqCst) {
955                other.abort();
956                continue;
957            }
958            match other.await {
959                Ok(read) => results.extend(read),
960                Err(error) => {
961                    if let Ok(panic) = error.try_into_panic() {
962                        std::panic::resume_unwind(panic);
963                    }
964                }
965            }
966        }
967        results
968    }
969
970    /// Takes transactions until none is left and runs Check #6 for each.
971    fn read(
972        &self,
973        authority_state: &AuthorityState,
974        epoch_store: &Arc<AuthorityPerEpochStore>,
975        reader: &CommitIndexedReader,
976        deny_config: &dyn DenyRuleConfig,
977    ) -> Vec<(usize, IotaResult<ValidationAtCommit>)> {
978        let mut results = Vec::new();
979        while let Some((i, transaction, attested)) = self
980            .transactions
981            .get(self.next.fetch_add(1, Ordering::SeqCst))
982        {
983            results.push((
984                *i,
985                authority_state.handle_transaction_validation_checks_at_commit(
986                    reader,
987                    transaction,
988                    epoch_store,
989                    deny_config,
990                    VerifierLimitsSource::ProtocolConfig,
991                    *attested,
992                ),
993            ));
994        }
995        results
996    }
997}

999/// One of Checks #2 to #4, which read no store.
1000#[derive(Clone, Copy, Debug, PartialEq, Eq)]
1001enum NoStoreCheck {
1002    /// Check #2, `validity_check`.
1003    Validity,
1004    /// Check #3, the attestor and the units of the attestation.
1005    Attestation,
1006    /// Check #3, the attestor is cut off for the rest of the epoch.
1007    AttestorCutOff,
1008    /// Check #3, the gas bounds of an attested transaction.
1009    GasBounds,
1010    /// Check #4, listing the owned inputs.
1011    OwnedInputs,
1012}
1013
1014/// Runs Checks #2 to #4 for one copy of a user transaction, in order. Returns
1015/// the owned inputs Check #4 lists, or the first check that failed with its
1016/// error. `attestors_cut_off` is filled when an attested copy gets that far.
1017fn checks_reading_no_store(
1018    epoch_store: &AuthorityPerEpochStore,
1019    commit_index: CommitIndex,
1020    tx: &VerifiedSequencedConsensusTransaction,
1021    transaction: &TransactionEnvelope,
1022    attestation: Option<&Attestation>,
1023    attestors_cut_off: &mut Option<BTreeSet<u8>>,
1024) -> Result<Vec<ObjectReference>, (NoStoreCheck, IotaError)> {
1025    let protocol_config = epoch_store.protocol_config();
1026
1027    // Check #2: Structural validity.
1028    transaction
1029        .validity_check(&epoch_store.tx_validity_check_context())
1030        .map_err(|e| (NoStoreCheck::Validity, e))?;
1031
1032    // Check #3: Attestation checks (attested transactions only).
1033    // The block signature transitively authenticates the attestation;
1034    // verify the claimed attestor matches the actual block author, that
1035    // the payload is not malformed and that the attestor is not cut off.
1036    if let Some(attestation) = attestation {
1037        let block_author = u8::try_from(tx.0.certificate_author_index)
1038            .expect("consensus committee indices should fit in a u8");
1039        let Attestation::Authority {
1040            authority_index, ..
1041        } = attestation;
1042        if *authority_index != block_author {
1043            return Err((
1044                NoStoreCheck::Attestation,
1045                IotaError::AttestationAuthorMismatch {
1046                    expected: *authority_index,
1047                    actual: block_author,
1048                },
1049            ));
1050        }
1051        check_attested_units(protocol_config, transaction, attestation)
1052            .map_err(|e| (NoStoreCheck::Attestation, e))?;
1053        if attestors_cut_off
1054            .get_or_insert_with(|| {
1055                epoch_store.attestors_cut_off_as_of(horizon(protocol_config, commit_index))
1056            })
1057            .contains(authority_index)
1058        {
1059            return Err((
1060                NoStoreCheck::AttestorCutOff,
1061                IotaError::AttestorCutOff {
1062                    attestor: *authority_index,
1063                },
1064            ));
1065        }
1066
1067        // Payload-only gas bounds: a pure function of the transaction and
1068        // epoch constants, so this drop needs no store read. The full gas
1069        // check (owner, coin type, balance) runs with the loaded coins in
1070        // Check #6.
1071        let data = transaction.data().transaction();
1072        check_gas_bounds(
1073            protocol_config,
1074            epoch_store.reference_gas_price(),
1075            data.gas_price(),
1076            data.gas_budget(),
1077        )
1078        .map_err(|e| (NoStoreCheck::GasBounds, e.into()))?;
1079    }
1080
1081    // Check #4: Extract owned input objects for lock conflict detection.
1082    extract_owned_input_objects(tx).map_err(|e| (NoStoreCheck::OwnedInputs, e))
1083}

1085/// The decision so far for each user transaction digest of a commit.
1086#[derive(Default)]
1087struct CommitDecisions {
1088    /// The decision of the last copy of each digest validated, with the error
1089    /// of a drop.
1090    verdicts: HashMap<TransactionDigest, (PostConsensusDecision, Option<IotaError>)>,
1091    /// The digests no later copy can change the decision of: a copy was
1092    /// kept, or dropped for a reason every copy shares.
1093    decided: HashSet<TransactionDigest>,
1094}
1095
1096impl CommitDecisions {
1097    fn is_decided(&self, digest: &TransactionDigest) -> bool {
1098        self.decided.contains(digest)
1099    }
1100
1101    /// Records the decision of `digest`, with the error of a drop.
1102    fn decide(
1103        &mut self,
1104        digest: TransactionDigest,
1105        decision: PostConsensusDecision,
1106        error: Option<IotaError>,
1107    ) {
1108        self.verdicts.insert(digest, (decision, error));
1109        self.decided.insert(digest);
1110    }
1111
1112    /// Records the drop of one copy of `digest` with `error`. `missing` is
1113    /// whether an input was not visible at the horizon. A drop that may come
1114    /// from the copy's own signatures leaves the digest open for a later copy;
1115    /// it is saved as [`PostConsensusDecision::DroppedCopy`] unless an input
1116    /// was not visible, which is not final either.
1117    fn drop_copy(
1118        &mut self,
1119        digest: TransactionDigest,
1120        error: IotaError,
1121        missing: bool,
1122        from_signatures: bool,
1123    ) {
1124        if from_signatures && missing {
1125            self.verdicts.insert(
1126                digest,
1127                (
1128                    PostConsensusDecision::DroppedInputNotVisibleYet,
1129                    Some(error),
1130                ),
1131            );
1132        } else if from_signatures {
1133            self.verdicts
1134                .insert(digest, (PostConsensusDecision::DroppedCopy, Some(error)));
1135        } else if missing {
1136            self.decide(
1137                digest,
1138                PostConsensusDecision::DroppedInputNotVisibleYet,
1139                Some(error),
1140            );
1141        } else {
1142            self.decide(digest, PostConsensusDecision::Dropped, Some(error));
1143        }
1144    }
1145}

1147/// The check a copy of a transaction failed, for
1148/// [`drop_may_come_from_signatures`].
1149enum FailedCheck<'a> {
1150    /// `validity_check`, with its error.
1151    Validity(&'a IotaError),
1152    /// The attestation of this copy: its attestor or its units.
1153    Attestation,
1154    /// Listing the owned inputs.
1155    OwnedInputs,
1156    /// Another transaction holds a lock on this input.
1157    LockConflict(&'a ObjectReference),
1158    /// The commit-indexed reader dropped this input or did not see it.
1159    Input(&'a InputObjectKind),
1160    /// A check whose outcome is the same for every copy.
1161    Data,
1162    /// Any other check of the inputs, deny rules and gas.
1163    Other,
1164}
1165
1166/// Whether a drop of this copy of a transaction may come from its signatures
1167/// rather than from the transaction data, which every copy of the digest
1168/// shares.
1169///
1170/// Block verification checks every signature against the data, except a Move
1171/// authenticator, which it checks only for the address it claims. So a copy
1172/// without one fails like every other copy, while a faulty validator can put
1173/// in its block a copy with a made-up authenticator that fails here. For a
1174/// copy with a Move authenticator, a drop counts as the data's only when the
1175/// data alone explains it: the data fails its own validity check or has
1176/// expired, its inputs cannot be listed, or the conflicting lock or the
1177/// dropped or unseen input is one the data names, or the package holding a
1178/// signer account's authenticate function is denied. Any other drop of such
1179/// a copy, including the other checks of the inputs, deny rules and gas, may
1180/// come from the authenticator. A failed attestation is the copy's own
1181/// whatever its signatures: a later copy may carry a valid one.
1182fn drop_may_come_from_signatures(
1183    transaction: &SenderSignedTransaction,
1184    check: FailedCheck<'_>,
1185    config: &ProtocolConfig,
1186) -> bool {
1187    if matches!(check, FailedCheck::Attestation) {
1188        return true;
1189    }
1190    if transaction.move_authenticators().is_empty() {
1191        return false;
1192    }
1193    let data = transaction.transaction();
1194    let data_names = |kind: &InputObjectKind| {
1195        data.input_objects()
1196            .is_ok_and(|inputs| inputs.contains(kind))
1197    };
1198    match check {
1199        FailedCheck::Attestation => true,
1200        FailedCheck::Validity(error) => {
1201            !matches!(error, IotaError::TransactionExpired)
1202                && !data.is_system_tx()
1203                && data.validity_check(config).is_ok()
1204        }
1205        FailedCheck::OwnedInputs => data.input_objects().is_ok(),
1206        FailedCheck::LockConflict(obj_ref) => {
1207            !data_names(&InputObjectKind::ImmOrOwnedMoveObject(*obj_ref))
1208        }
1209        FailedCheck::Input(kind) => {
1210            !data_names(kind)
1211                && !matches!(
1212                    kind,
1213                    InputObjectKind::ImmOrOwnedMoveObject(obj_ref)
1214                        if data.receiving_objects().contains(obj_ref)
1215                )
1216        }
1217        FailedCheck::Data => false,
1218        FailedCheck::Other => true,
1219    }
1220}

1222/// Narrows the byte-derived owned inputs of an already-executed transaction to
1223/// the references it consumed — the same set the main path locks — by
1224/// intersecting them with the pre-execution references in its own effects;
1225/// immutable inputs never appear there. A missing effects body
1226/// is a storage error, never a "not executed" verdict, which would drop a
1227/// committee-agreed winner other validators keep.
1228fn filter_locked_inputs_by_effects(
1229    authority_state: &AuthorityState,
1230    digest: &TransactionDigest,
1231    owned_inputs: Vec<ObjectReference>,
1232) -> IotaResult<Vec<ObjectReference>> {
1233    let effects = authority_state
1234        .get_transaction_cache_reader()
1235        .try_get_executed_effects(digest)?
1236        .ok_or_else(|| IotaError::GenericAuthority {
1237            error: format!(
1238                "effects of already-executed transaction {digest:?} are unavailable in \
1239                 post-consensus validation"
1240            ),
1241        })?;
1242    // Owned inputs always appear in effects and immutable ones never do
1243    // (`TemporaryStore::ensure_active_inputs_mutated` force-mutates every
1244    // non-immutable owned input); intersecting on the full `ObjectReference`
1245    // — the lock table's own key — keeps the sets identical by construction.
1246    let consumed: HashSet<ObjectReference> = effects
1247        .old_object_metadata()
1248        .into_iter()
1249        .map(|old| *old.reference())
1250        .collect();
1251    Ok(owned_inputs
1252        .into_iter()
1253        .filter(|obj_ref| consumed.contains(obj_ref))
1254        .collect())
1255}

1257/// Finds an existing owned-object lock on `obj_ref`, walking three tiers in
1258/// order:
1259/// 1. `current_commit_locks` — locks acquired earlier in the same commit.
1260/// 2. Consensus quarantine — locks from previous uncommitted commits.
1261/// 3. Persistent DB — committed locks.
1262///
1263/// Returns `Ok(Some(locker))` if any tier holds a lock, `Ok(None)` if the
1264/// input is free. The caller decides what to do with the result (drop with
1265/// `ObjectLockConflict` for a contender, or `fatal!` if a winner is
1266/// out-locked).
1267fn find_existing_lock(
1268    obj_ref: &ObjectReference,
1269    current_commit_locks: &HashMap<ObjectReference, LockDetails>,
1270    epoch_store: &Arc<AuthorityPerEpochStore>,
1271) -> IotaResult<Option<LockDetails>> {
1272    if let Some(&locker) = current_commit_locks.get(obj_ref) {
1273        return Ok(Some(locker));
1274    }
1275    if let Some(locker) = epoch_store.get_quarantined_owned_object_lock(obj_ref) {
1276        return Ok(Some(locker));
1277    }
1278    epoch_store.tables()?.get_locked_transaction(obj_ref)
1279}

1281/// Extracts the `ImmOrOwnedMoveObject` input references of a
1282/// `UserTransactionV1` consensus transaction (excludes shared objects and
1283/// packages).
1284///
1285/// This is the set probed for lock conflicts, not the set that gets locked.
1286/// It is derived from the transaction bytes alone, where owned and immutable
1287/// inputs share one kind, so it cannot tell them apart; the callers that
1288/// acquire locks narrow it down first. Probing immutable references is
1289/// harmless, since no tier ever holds a lock on one.
1290fn extract_owned_input_objects(
1291    tx: &VerifiedSequencedConsensusTransaction,
1292) -> IotaResult<Vec<ObjectReference>> {
1293    let Some(transaction_data) = (match &tx.0.transaction {
1294        SequencedConsensusTransactionKind::External(ext) => {
1295            ext.kind.as_user_transaction().map(|t| t.data())
1296        }
1297        SequencedConsensusTransactionKind::System(_) => None,
1298    }) else {
1299        return Err(IotaError::GenericAuthority {
1300            error: "Expected UserTransactionV1 in extract_owned_input_objects".to_string(),
1301        });
1302    };
1303
1304    // Use SenderSignedTransaction::input_objects() rather than
1305    // Transaction::input_objects() to also include objects coming from
1306    // MoveAuthenticator signatures. Those can only be immutable or shared,
1307    // so they widen the probe set but never the locked set. Packages are left
1308    // out below anyway.
1309    let owned_objects = transaction_data
1310        .input_objects(false)?
1311        .into_iter()
1312        .filter_map(|input| match input {
1313            InputObjectKind::ImmOrOwnedMoveObject(obj_ref) => Some(obj_ref),
1314            InputObjectKind::SharedMoveObject { .. } => None,
1315            InputObjectKind::MovePackage(_) => None,
1316        })
1317        .collect();
1318
1319    Ok(owned_objects)
1320}
