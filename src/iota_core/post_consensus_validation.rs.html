4//! Post-consensus validation and owned-object conflict resolution for
5//! `UserTransactionV1` transactions.
6//!
7//! This module merges two formerly separate pipeline stages into a single pass:
8//!
9//! 1. **Semantic validation** — deduplication, already-executed check, structural validity, and
10//!    deny checks (deny lists, gas, ownership, coin deny list, Move authenticator).
11//! 2. **Owned-object conflict resolution** (white-flag) — three-tier lock check and lock
12//!    acquisition.
13//!
14//! Processing both in one loop avoids iterating over every transaction twice
15//! and skips expensive validation for transactions that can't acquire object
16//! locks anyway.
17//!
18//! # Per-transaction order within the loop
19//!
20//! 1. Non-`UserTransactionV1` — pass through unchanged.
21//! 2. Dedup by `ConsensusTransactionKey` — silent drop. With deterministic validation, a later copy
22//!    of a user transaction with other signatures is validated when every earlier copy was dropped
23//!    for a reason that may come from its own signatures (see `drop_may_come_from_signatures`).
24//! 3. Saved decisions, already-executed and deferred transactions:
25//!    - Replayed commit (deterministic validation only): a commit replayed after a restart repeats
26//!      the decisions saved on its first run. A saved drop is repeated without checks. Once the
27//!      switch to executing synced checkpoints after commit `L` is saved, a commit at or below `L`
28//!      repeats a saved keep without checks and takes no locks for it. Otherwise a saved keep is
29//!      validated again unless the transaction has executed or was deferred at an earlier commit.
30//!    - Already executed (typically by state sync): the transaction is **retained** as a
31//!      committee-agreed winner, not dropped: dropping it would make this validator's checkpoints
32//!      differ from those of the other validators. It registers the locks its own effects report
33//!      and skips re-validation. With deterministic validation this applies only if the first run
34//!      of this commit saved a keep for it; otherwise it goes through the checks below like any
35//!      other transaction, unless it was deferred.
36//!    - Deferred at an earlier commit (deterministic validation only): the transaction is kept
37//!      without checks and takes no new locks. It was validated at the commit that kept it and
38//!      still holds the locks it took there.
39//! 4. `validity_check()` — drop with error.
40//! 5. Three-tier lock conflict check (local HashMap → quarantine → DB) — drop with error, except a
41//!    lock held by the same transaction (with deterministic validation off, a deferred tx's own
42//!    lock from the commit that kept it), which is exempt. Cheap; performed before expensive
43//!    checks.
44//! 6. `handle_transaction_validation_checks()` — drop with error. Only reached when all locks are
45//!    free.
46//! 7. All passed — acquire locks in the local tracking map, keep transaction.
47//!
48//! Non-`UserTransactionV1` transactions pass through unchanged.
49//!
50//! # Which references get locked
51//!
52//! Step 5 probes every `ImmOrOwnedMoveObject` reference, but only genuinely
53//! owned references are locked — an immutable input never takes a new
54//! version, so its lock would hold until the epoch ends. Step 7 filters via
55//! the loaded objects, step 3 via the executed transaction's effects.

94/// The post-consensus validation decision for one transaction at one
95/// consensus commit.
96///
97/// Saved in the epoch tables, so its encoding must stay readable by other
98/// binaries within the epoch: variants carry no data and new ones go at the
99/// end.
100#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
101pub enum PostConsensusDecision {
102    /// The transaction stayed in the commit.
103    Kept,
104    /// The transaction was dropped.
105    Dropped,
106    /// The transaction was dropped because an input is not visible at the
107    /// commit's [horizon](crate::post_consensus_input_reader::reader::horizon)
108    /// yet. The digest can be kept when sequenced again, so the drop is not
109    /// its final status.
110    DroppedInputNotVisibleYet,
111    /// The copy of the transaction validated last was dropped for a reason
112    /// that may come from its own signatures, which other copies of the
113    /// digest do not share. Another copy can be kept when sequenced, so the
114    /// drop is not the final status of the digest.
115    DroppedCopy,
116}
117
118/// A post-consensus validation decision as saved, so a replay of the commit
119/// after a restart reaches the same decision.
120///
121/// The error of a drop is kept as BCS bytes and decoded on its own, so a
122/// binary that encodes `IotaError` differently still reads the decision.
123#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
124pub(crate) struct SavedPostConsensusDecision {
125    pub(crate) decision: PostConsensusDecision,
126    /// The BCS bytes of the drop's error; empty for a keep.
127    pub(crate) error: Vec<u8>,
128}
129
130impl SavedPostConsensusDecision {
131    pub(crate) fn kept() -> Self {
132        Self {
133            decision: PostConsensusDecision::Kept,
134            error: Vec::new(),
135        }
136    }
137
138    pub(crate) fn dropped(decision: PostConsensusDecision, error: &IotaError) -> Self {
139        Self {
140            decision,
141            error: bcs::to_bytes(error).expect("an IotaError should encode to BCS"),
142        }
143    }
144
145    /// The error of a saved drop, or `IotaError::Unknown` if this binary
146    /// cannot decode it.
147    pub(crate) fn error(&self) -> IotaError {
148        bcs::from_bytes(&self.error).unwrap_or_else(|e| {
149            IotaError::Unknown(format!(
150                "the saved error of a post-consensus drop cannot be decoded: {e}"
151            ))
152        })
153    }
154}

156/// Validates `UserTransactionV1` transactions and resolves owned-object
157/// conflicts in a single pass.
158///
159/// For each `UserTransactionV1` in consensus order:
160/// - Runs deduplication, structural validity, lock conflict check, and deny checks (deny list, gas,
161///   ownership, coin deny list, Move authenticator).
162/// - If all checks pass, acquires owned-object locks in a local tracking map; immutable inputs are
163///   not locked, as an immutable input never takes a new version and its lock would hold until the
164///   epoch ends.
165/// - Drops the transaction (with an error) on any failure.
166/// - An already-executed transaction is **retained** (not dropped): it registers the locks its
167///   effects report and skips re-validation. Dropping it would make this validator's checkpoints
168///   differ from those of the other validators.
169/// - With deterministic validation, a transaction in `previously_deferred` is kept without checks
170///   and takes no new locks: the locks it took at the commit that kept it stay in place.
171///
172/// With deterministic validation, copies of one digest with other signatures can come from
173/// different authors in one commit. The first copy is validated; a later one only while every
174/// earlier copy was dropped for a reason that may come from its own signatures. The digest's
175/// decision is that of the last copy validated, and only a kept copy stays in `transactions`.
176///
177/// With deterministic validation, the decision for every candidate is saved before returning,
178/// including keeps that the caller then defers, and a commit replayed after a restart repeats the
179/// saved decisions; step 3 of the module docs says which transactions are validated again. Panics
180/// if the saved decisions are incomplete, the candidates differ from the saved ones, or a saved
181/// keep is now dropped. Once the switch to executing synced checkpoints after commit `L` is saved,
182/// also panics for a commit above `L`, or for a commit at or below `L` without saved decisions.
183///
184/// Non-`UserTransactionV1` transactions pass through unchanged.
185///
186/// # Arguments
187///
188/// * `authority_state` — Used for cache reads and deny checks.
189/// * `epoch_store` — Current epoch store (protocol config, lock storage, governance deny rules).
190/// * `commit_index` — The consensus commit being validated. With deterministic validation on,
191///   inputs are read as of this commit.
192/// * `deterministic_validation` — The `enable_pcool_flow` flag, read once per commit by the caller
193///   so every step of the commit decides on the same value.
194/// * `previously_deferred` — The transactions deferred at earlier commits and reloaded into
195///   `transactions`, randomness-using ones included. Read only with deterministic validation.
196/// * `transactions` — All sequenced transactions for this consensus commit; modified in-place.
197///
198/// # Returns
199///
200/// `Ok((dropped, locks, all_user_tx_digests))` where:
201/// - `dropped` — `(digest, error, decision)` for every semantically-invalid or lock-conflicting
202///   transaction, where `decision` is never `Kept`. Without deterministic validation it is always
203///   `Dropped`. Silent drops (duplicates) are **not** included.
204/// - `locks` — Owned-object locks acquired in this commit, to be stored in the consensus quarantine
205///   so subsequent commits can see them.
206/// - `all_user_tx_digests` — Every `UserTransactionV1` digest that passed dedup (both kept and
207///   dropped), once each. Used by the caller to release pre-consensus soft locks.
208pub async fn validate_and_resolve_conflicts(
209    authority_state: &AuthorityState,
210    epoch_store: &Arc<AuthorityPerEpochStore>,
211    commit_index: CommitIndex,
212    deterministic_validation: bool,
213    previously_deferred: &PreviouslyDeferredTransactions,
214    transactions: &mut Vec<VerifiedSequencedConsensusTransaction>,
215) -> IotaResult<(
216    Vec<(TransactionDigest, IotaError, PostConsensusDecision)>,
217    HashMap<ObjectReference, LockDetails>,
218    Vec<TransactionDigest>,
219)> {
220    // Keys of the transactions other than user transactions seen so far.
221    let mut seen_keys: HashSet<SequencedConsensusTransactionKey> = HashSet::new();
222    // The signatures of each copy of a digest validated at this commit, in
223    // consensus order.
224    let mut validated_copies: HashMap<TransactionDigest, Vec<&[UserSignature]>> = HashMap::new();
225    let mut decisions = CommitDecisions::default();
226    // Every validated copy's digest, in consensus order: a digest appears once
227    // per copy validated.
228    let mut candidates = Vec::with_capacity(transactions.len());
229    // Locks acquired within this commit. Populated for every transaction that
230    // passes all checks; used by subsequent transactions' conflict checks.
231    let mut current_commit_locks: HashMap<ObjectReference, LockDetails> = HashMap::new();
232    // Index-parallel keep flags: true = keep, false = remove.
233    let mut keep = vec![true; transactions.len()];
234    // All UserTransactionV1 digests seen in this commit (both kept and dropped),
235    // used by the caller to release pre-consensus soft locks.
236    let mut all_user_tx_digests = Vec::with_capacity(transactions.len());
237
238    // One deny-rule snapshot for the whole commit, so every transaction in it
239    // is judged by the same set. With governance enabled this must be the
240    // consensus-derived set — local config can differ between validators and
241    // would fork the post-consensus decisions.
242    let governance_deny_rules;
243    let deny_config: &dyn DenyRuleConfig = if epoch_store.protocol_config().enable_pcool_flow() {
244        governance_deny_rules = epoch_store.get_active_transaction_deny_rules();
245        governance_deny_rules.as_ref()
246    } else {
247        &authority_state.config.transaction_deny_config
248    };
249
250    // With deterministic validation, the decisions saved when this commit was
251    // first validated, present only when it is replayed after a restart. A
252    // saved candidate list means every candidate has a saved decision.
253    let saved_candidates = if deterministic_validation {
254        epoch_store
255            .tables()?
256            .post_consensus_decision_candidates
257            .get(&commit_index)?
258    } else {
259        None
260    };
261    // A node that switched to executing synced checkpoints after commit
262    // `last` replays only the commits up to it after a restart. Synced
263    // checkpoints have since written outputs without handler rows, which the
264    // reader cannot place, so these commits repeat their saved decisions.
265    let replaying_up_to_the_switch = if deterministic_validation {
266        match epoch_store.last_commit_before_synced_checkpoint_execution()? {
267            Some(last) if commit_index > last => fatal!(
268                "commit {commit_index} validated after the switch to synced checkpoints \
269                 after commit {last}"
270            ),
271            Some(last) if saved_candidates.is_none() => fatal!(
272                "commit {commit_index} has no saved decisions although the switch to synced \
273                 checkpoints after commit {last} saved every decision up to it"
274            ),
275            Some(_) => true,
276            None => false,
277        }
278    } else {
279        false
280    };
281    // How many copies of each digest the first run validated. The decision
282    // of the last one is the digest's; the ones before it were dropped for
283    // their own signatures.
284    let mut saved_copies: HashMap<TransactionDigest, usize> = HashMap::new();
285    for digest in saved_candidates.iter().flatten() {
286        *saved_copies.entry(*digest).or_default() += 1;
287    }
288    let mut saved_decisions = HashMap::new();
289
290    // One reader for the whole commit, so every transaction in it is read as
291    // of the same commit index.
292    let reader = deterministic_validation.then(|| {
293        CommitIndexedReader::new(
294            authority_state.get_object_cache_reader().clone(),
295            epoch_store.clone(),
296            commit_index,
297        )
298    });
299
300    for (i, tx) in transactions.iter().enumerate() {
301        // Only validate UserTransactionV1; pass everything else through
302        // unchanged, once per key.
303        let Some(transaction) = (match &tx.0.transaction {
304            SequencedConsensusTransactionKind::External(ext) => ext.kind.as_user_transaction(),
305            SequencedConsensusTransactionKind::System(_) => None,
306        }) else {
307            if !seen_keys.insert(tx.0.key()) {
308                keep[i] = false;
309            }
310            continue;
311        };
312
313        let digest = *transaction.digest();
314        let signatures = transaction.data().signatures();
315
316        // Check #0: Dedup by digest.
317        // The same UserTransactionV1 may appear in DAG blocks from multiple
318        // validators within the same consensus commit. Silent drop — not added
319        // to `dropped`. With deterministic validation, a copy with other
320        // signatures is validated while no earlier copy has decided the
321        // digest. A copy with the same signatures as one already validated
322        // would get the same decision.
323        let copies = validated_copies.entry(digest).or_default();
324        if copies.is_empty() {
325            all_user_tx_digests.push(digest);
326        } else if !deterministic_validation
327            || decisions.is_decided(&digest)
328            || copies.contains(&signatures)
329        {
330            keep[i] = false;
331            continue;
332        }
333        copies.push(signatures);
334        let copy_number = copies.len();
335        candidates.push(digest);
336
337        let saved = match &saved_candidates {
338            Some(_) => {
339                if copy_number < saved_copies.get(&digest).copied().unwrap_or_default() {
340                    keep[i] = false;
341                    continue;
342                }
343                match epoch_store.post_consensus_decision(commit_index, digest)? {
344                    Some(saved) => Some(saved),
345                    None => fatal!(
346                        "commit {commit_index} has a saved candidate list but no saved \
347                         validation decision for {digest:?}"
348                    ),
349                }
350            }
351            None => None,
352        };
353        let saved_decision = saved.as_ref().map(|saved| saved.decision);
354        if let Some(decision) = saved_decision {
355            saved_decisions.insert(digest, decision);
356        }
357        // A saved drop is replayed as is: the inputs it was decided on may
358        // have changed since.
359        if let Some(saved) = saved.filter(|saved| saved.decision != PostConsensusDecision::Kept) {
360            decisions.decide(digest, saved.decision, Some(saved.error()));
361            keep[i] = false;
362            continue;
363        }
364        // Its locks are not registered: nothing in this epoch reads them, as
365        // every transaction up to the switch repeats its saved decision and no
366        // commit after it is validated.
367        if replaying_up_to_the_switch && saved_decision == Some(PostConsensusDecision::Kept) {
368            debug!(
369                ?digest,
370                "Repeating the saved keep up to the synced checkpoint switch"
371            );
372            decisions.decide(digest, PostConsensusDecision::Kept, None);
373            continue;
374        }
375        // Validating it again could drop it, and the locks it took at the
376        // commit that kept it would then stay until the epoch ends. Later
377        // contenders find those locks in the quarantine or the lock table.
378        if deterministic_validation && previously_deferred.contains_key(&digest) {
379            debug!(
380                ?digest,
381                "Keeping a transaction deferred at an earlier commit without validating it again"
382            );
383            decisions.decide(digest, PostConsensusDecision::Kept, None);
384            continue;
385        }
386        // Whether a drop of this copy may come from its own signatures, so a
387        // later copy of the digest is validated. Only with deterministic
388        // validation, which is what lets later copies reach this loop.
389        let from_signatures = |check: FailedCheck<'_>| {
390            deterministic_validation
391                && drop_may_come_from_signatures(
392                    transaction.data(),
393                    check,
394                    epoch_store.protocol_config(),
395                )
396        };
397
398        // Check #1: Already executed (typically by state-sync before this node's
399        // consensus handler reached the commit). It is a committee-agreed winner, so
400        // keep it in the sequence to flow into checkpoint roots like on every other
401        // validator (dropping it would make this validator's checkpoint differ from
402        // those of the others). Register its owned-object locks so double-spend
403        // siblings still lose, then skip re-validation (#2/#5);
404        // the active scheduler's enqueue filter suppresses the re-execution.
405        //
406        // With deterministic validation, effects alone do not show at which
407        // commit the transaction was kept, so only a saved keep at this commit
408        // skips validation; its consumed inputs may have left the live state by
409        // now. Without one, the commit-indexed reader decides, as on every
410        // other validator.
411        if (!deterministic_validation || saved_decision == Some(PostConsensusDecision::Kept))
412            && authority_state
413                .get_transaction_cache_reader()
414                .try_is_tx_already_executed(&digest)?
415        {
416            // Byte-based, so safe even though the inputs are already consumed.
417            let owned_inputs = filter_locked_inputs_by_effects(
418                authority_state,
419                &digest,
420                extract_owned_input_objects(tx)?,
421            )?;
422            for obj_ref in &owned_inputs {
423                // A winner cannot be out-locked: after the effects filter,
424                // every reference here was consumed by this transaction, so a
425                // lock held by a different tx is a consistency violation, not
426                // a conflict. (Flag off, immutable references, which are not
427                // consumed, stay in the set and weaken this invariant.)
428                if let Some(other) =
429                    find_existing_lock(obj_ref, &current_commit_locks, epoch_store)?
430                {
431                    if other != digest {
432                        fatal!(
433                            "already-executed transaction {:?} has owned input {:?} \
434                             locked by a different transaction {:?}",
435                            digest,
436                            obj_ref,
437                            other,
438                        );
439                    }
440                }
441                current_commit_locks.insert(*obj_ref, digest);
442            }
443            debug!(
444                ?digest,
445                num_owned_inputs = owned_inputs.len(),
446                "Transaction already executed; retained as checkpoint root, skipping re-validation"
447            );
448            // keep[i] stays true so the transaction remains in the sequence.
449            decisions.decide(digest, PostConsensusDecision::Kept, None);
450            continue;
451        }
452
453        // Check #2: Structural validity.
454        if let Err(e) = transaction.validity_check(&epoch_store.tx_validity_check_context()) {
455            warn!(
456                ?digest,
457                commit_index,
458                error = ?e,
459                "UserTransactionV1 failed validity_check post-consensus, dropping"
460            );
461            let from_signatures = from_signatures(FailedCheck::Validity(&e));
462            decisions.drop_copy(digest, e, false, from_signatures);
463            keep[i] = false;
464            continue;
465        }
466
467        // Check #3: Extract owned input objects for lock conflict detection.
468        let owned_inputs = match extract_owned_input_objects(tx) {
469            Ok(inputs) => inputs,
470            Err(e) => {
471                warn!(
472                    ?digest,
473                    commit_index,
474                    error = ?e,
475                    "Failed to extract owned input objects post-consensus, dropping"
476                );
477                decisions.drop_copy(digest, e, false, from_signatures(FailedCheck::OwnedInputs));
478                keep[i] = false;
479                continue;
480            }
481        };
482
483        // Check #4: Three-tier lock conflict check.
484        // Cheap (HashMap + quarantine + DB lookups); performed before the
485        // expensive deny checks so conflicting transactions are filtered first.
486        //
487        // Locks are keyed by full ObjectReference (id + version + digest), not just
488        // ObjectID. Two transactions referencing the same object at different
489        // versions will NOT conflict here — version freshness is validated
490        // later in Check #5 (deny checks load objects from DB and verify
491        // that the transaction's input refs match the current state).
492        //
493        // Probing the raw set is safe though immutable inputs are never
494        // locked: acquisition never inserts one, and the lock tables are
495        // epoch-scoped while the protocol config is fixed per epoch, so no
496        // tier can hold a stale immutable lock.
497        //
498        // Tier 1: Local HashMap (current commit).
499        // Tier 2: Consensus quarantine (previous uncommitted commits).
500        // Tier 3: Persistent DB (committed data).
501        let mut conflict: Option<(ObjectReference, IotaError)> = None;
502        for obj_ref in &owned_inputs {
503            if let Some(locked_by) =
504                find_existing_lock(obj_ref, &current_commit_locks, epoch_store)?
505            {
506                // With deterministic validation off, a lock held by this same
507                // transaction is its own lock from an earlier commit: it acquired
508                // owned-object locks, was then deferred, and is reloaded and
509                // validated again in this commit. A self-held lock is NOT a conflict
510                // - without this guard, the transaction will be dropped with
511                // `ObjectLockConflict` and never executed. Check #1 accepts a
512                // lock held by the same transaction too.
513                //
514                // Note that same-commit duplicates cannot slip through here since
515                // Check #0 lets a later copy through only while no copy of the
516                // digest is kept, so a same-digest lock here is always this
517                // transaction's own prior-round lock.
518                if locked_by == digest {
519                    continue;
520                }
521
522                debug!(
523                    ?digest,
524                    ?obj_ref,
525                    ?locked_by,
526                    "Transaction conflicts with existing owned-object lock, dropping"
527                );
528                conflict = Some((
529                    *obj_ref,
530                    IotaError::ObjectLockConflict {
531                        obj_ref: *obj_ref,
532                        pending_transaction: locked_by,
533                    },
534                ));
535                break;
536            }
537        }
538        if let Some((obj_ref, e)) = conflict {
539            decisions.drop_copy(
540                digest,
541                e,
542                false,
543                from_signatures(FailedCheck::LockConflict(&obj_ref)),
544            );
545            keep[i] = false;
546            continue;
547        }
548
549        // Check #5: Deny list, gas, ownership, coin deny list, Move
550        // authenticator. Only reached if all locks are free — skips the
551        // expensive object loading for transactions that would be dropped
552        // by the lock conflict check.
553        //
554        // Safe to skip signature re-verification: the consensus block verifier
555        // (`IotaTxValidator::validate_transactions`) already called
556        // `verify_tx()` on every `UserTransactionV1` before accepting the
557        // block. Re-verifying here would not add safety — if a quorum
558        // committed a bad signature it indicates a protocol-level failure
559        // (2f+1 Byzantine/buggy validators), not something we can recover from
560        // by rejecting the transaction post-consensus. Doing so would also risk
561        // diverging from other honest validators.
562        let verified_tx = VerifiedTransaction::new_from_verified((*transaction).clone());
563        // The input the reader dropped or did not see, and whether it did
564        // not see it.
565        let mut input_verdict: Option<(InputObjectKind, bool)> = None;
566        let mut denied_for_every_copy = false;
567        let checked = match &reader {
568            // Inputs read as of the commit. A missing input is reported with
569            // the error admission gives a missing input, which the transaction
570            // and quorum drivers retry: it drops the transaction from this
571            // commit only, the decision is saved as `Missing`, and a
572            // resubmission can be kept at a later commit. A dropped input is
573            // final for the digest, so it has its own error, which the drivers
574            // do not retry (a drop that may come from the copy's signatures is
575            // not sent to the waiters). The reason goes to the log. The Move
576            // authenticator runs at execution instead. Here only whether each
577            // account is one is checked, and its authenticator function field
578            // is read for the deny check of its package, both as of the
579            // horizon. The coin deny list is read as of the horizon too.
580            Some(reader) => authority_state
581                .handle_transaction_validation_checks_at_commit(
582                    reader,
583                    &verified_tx,
584                    epoch_store,
585                    deny_config,
586                    VerifierLimitsSource::ProtocolConfig,
587                )
588                .and_then(|verdict| {
589                    let verdicts = &authority_state
590                        .metrics
591                        .consensus_handler_validation_reader_verdicts;
592                    match verdict {
593                        ValidationAtCommit::Keep(owned) => {
594                            verdicts.with_label_values(&["keep", "none"]).inc();
595                            Ok(owned)
596                        }
597                        ValidationAtCommit::Drop(kind, reason) => {
598                            verdicts
599                                .with_label_values(&["drop", &format!("{:?}", reason.kind())])
600                                .inc();
601                            warn!(
602                                ?digest,
603                                commit_index,
604                                ?kind,
605                                ?reason,
606                                "input dropped by the commit-indexed reader"
607                            );
608                            input_verdict = Some((kind, false));
609                            Err(kind.not_available_at_commit_error().into())
610                        }
611                        ValidationAtCommit::Missing(kind, reason) => {
612                            verdicts
613                                .with_label_values(&["missing", &format!("{:?}", reason.kind())])
614                                .inc();
615                            warn!(
616                                ?digest,
617                                commit_index,
618                                ?kind,
619                                ?reason,
620                                "input not visible at this commit"
621                            );
622                            input_verdict = Some((kind, true));
623                            Err(kind.object_not_found_error().into())
624                        }
625                        ValidationAtCommit::AuthenticatorPackageDenied(error) => {
626                            denied_for_every_copy = true;
627                            Err(error)
628                        }
629                    }
630                }),
631            None => {
632                authority_state
633                    .handle_transaction_validation_checks(
634                        &verified_tx,
635                        epoch_store,
636                        deny_config,
637                        // Epoch-gated coin deny-list read: the verdict here decides
638                        // whether the transaction stays in the committed set, so it
639                        // must not depend on this validator's execution progress.
640                        true,
641                        // Whether a published package stays in the commit must
642                        // not depend on this validator's own signing limits.
643                        VerifierLimitsSource::ProtocolConfig,
644                    )
645                    .await
646            }
647        };
648        let validated_owned_objects = match checked {
649            Ok(owned) => owned,
650            Err(e) => {
651                if e.is_storage_or_epoch_error() {
652                    return Err(e);
653                }
654                warn!(
655                    ?digest,
656                    commit_index,
657                    error = ?e,
658                    "UserTransactionV1 failed post-consensus deny checks, dropping"
659                );
660                let (missing, check) = match &input_verdict {
661                    Some((kind, missing)) => (*missing, FailedCheck::Input(kind)),
662                    None if denied_for_every_copy => (false, FailedCheck::Data),
663                    None => (false, FailedCheck::Other),
664                };
665                let from_signatures = from_signatures(check);
666                decisions.drop_copy(digest, e, missing, from_signatures);
667                keep[i] = false;
668                continue;
669            }
670        };
671
672        // All checks passed — acquire owned-object locks in local tracking.
673        // The validated set comes from loaded objects, so unlike the
674        // byte-derived `owned_inputs` it excludes immutable inputs, which must
675        // never be locked (see the module docs). It is a subset of `owned_inputs`,
676        // so every reference locked here was probed by Check #4 first.
677        for obj_ref in &validated_owned_objects {
678            current_commit_locks.insert(*obj_ref, digest);
679        }
680        // Log the acquired refs, not just their count, so the winner's locks
681        // are attributable per (object_id, version).
682        debug!(
683            ?digest,
684            num_owned_inputs = validated_owned_objects.len(),
685            owned_inputs = ?validated_owned_objects,
686            "Transaction passed post-consensus validation, acquired all object locks"
687        );
688        decisions.decide(digest, PostConsensusDecision::Kept, None);
689    }
690
691    let dropped: Vec<(TransactionDigest, IotaError, PostConsensusDecision)> = all_user_tx_digests
692        .iter()
693        .filter_map(|digest| match decisions.verdicts.get(digest) {
694            Some((decision, Some(error))) => Some((*digest, error.clone(), *decision)),
695            _ => None,
696        })
697        .collect();
698
699    if deterministic_validation {
700        match &saved_candidates {
701            Some(saved_candidates) => {
702                if *saved_candidates != candidates {
703                    fatal!(
704                        "validation candidates of commit {commit_index} differ from the saved \
705                         ones: saved {saved_candidates:?}, now {candidates:?}"
706                    );
707                }
708                for digest in &all_user_tx_digests {
709                    let decision = decisions.verdicts.get(digest).map(|(decision, _)| decision);
710                    let saved = saved_decisions.get(digest);
711                    if saved != decision {
712                        fatal!(
713                            "validation decision for {digest:?} at commit {commit_index} \
714                             differs from the saved one: saved {saved:?}, now {decision:?}"
715                        );
716                    }
717                }
718            }
719            None => {
720                // Every copy's entry carries the digest's decision.
721                let saved: Vec<_> = candidates
722                    .iter()
723                    .map(|digest| {
724                        let saved = match decisions
725                            .verdicts
726                            .get(digest)
727                            .expect("every validated copy decides its digest")
728                        {
729                            (decision, Some(error)) => {
730                                SavedPostConsensusDecision::dropped(*decision, error)
731                            }
732                            (_, None) => SavedPostConsensusDecision::kept(),
733                        };
734                        (*digest, saved)
735                    })
736                    .collect();
737                epoch_store.persist_post_consensus_decisions(commit_index, &saved)?;
738                if !saved.is_empty() {
739                    fail_point!("crash-after-post-consensus-decisions");
740                }
741            }
742        }
743    }
744
745    if !dropped.is_empty() {
746        warn!(
747            num_dropped = dropped.len(),
748            num_retained = transactions
749                .iter()
750                .enumerate()
751                .filter(|(i, _)| keep[*i])
752                .count(),
753            "Post-consensus validation dropped transactions"
754        );
755    }
756
757    // Remove invalid/duplicate/conflicting entries using the parallel keep
758    // flags.
759    let mut iter = keep.into_iter();
760    transactions.retain(|_| iter.next().unwrap_or(true));
761
762    Ok((dropped, current_commit_locks, all_user_tx_digests))
763}

765/// The decision so far for each user transaction digest of a commit.
766#[derive(Default)]
767struct CommitDecisions {
768    /// The decision of the last copy of each digest validated, with the error
769    /// of a drop.
770    verdicts: HashMap<TransactionDigest, (PostConsensusDecision, Option<IotaError>)>,
771    /// The digests no later copy can change the decision of: a copy was
772    /// kept, or dropped for a reason every copy shares.
773    decided: HashSet<TransactionDigest>,
774}
775
776impl CommitDecisions {
777    fn is_decided(&self, digest: &TransactionDigest) -> bool {
778        self.decided.contains(digest)
779    }
780
781    /// Records the decision of `digest`, with the error of a drop.
782    fn decide(
783        &mut self,
784        digest: TransactionDigest,
785        decision: PostConsensusDecision,
786        error: Option<IotaError>,
787    ) {
788        self.verdicts.insert(digest, (decision, error));
789        self.decided.insert(digest);
790    }
791
792    /// Records the drop of one copy of `digest` with `error`. `missing` is
793    /// whether an input was not visible at the horizon. A drop that may come
794    /// from the copy's own signatures leaves the digest open for a later copy;
795    /// it is saved as [`PostConsensusDecision::DroppedCopy`] unless an input
796    /// was not visible, which is not final either.
797    fn drop_copy(
798        &mut self,
799        digest: TransactionDigest,
800        error: IotaError,
801        missing: bool,
802        from_signatures: bool,
803    ) {
804        if from_signatures && missing {
805            self.verdicts.insert(
806                digest,
807                (
808                    PostConsensusDecision::DroppedInputNotVisibleYet,
809                    Some(error),
810                ),
811            );
812        } else if from_signatures {
813            self.verdicts
814                .insert(digest, (PostConsensusDecision::DroppedCopy, Some(error)));
815        } else if missing {
816            self.decide(
817                digest,
818                PostConsensusDecision::DroppedInputNotVisibleYet,
819                Some(error),
820            );
821        } else {
822            self.decide(digest, PostConsensusDecision::Dropped, Some(error));
823        }
824    }
825}

827/// The check a copy of a transaction failed, for
828/// [`drop_may_come_from_signatures`].
829enum FailedCheck<'a> {
830    /// `validity_check`, with its error.
831    Validity(&'a IotaError),
832    /// Listing the owned inputs.
833    OwnedInputs,
834    /// Another transaction holds a lock on this input.
835    LockConflict(&'a ObjectReference),
836    /// The commit-indexed reader dropped this input or did not see it.
837    Input(&'a InputObjectKind),
838    /// A check whose outcome is the same for every copy.
839    Data,
840    /// Any other check of the inputs, deny rules and gas.
841    Other,
842}
843
844/// Whether a drop of this copy of a transaction may come from its signatures
845/// rather than from the transaction data, which every copy of the digest
846/// shares.
847///
848/// Block verification checks every signature against the data, except a Move
849/// authenticator, which it checks only for the address it claims. So a copy
850/// without one fails like every other copy, while a faulty validator can put
851/// in its block a copy with a made-up authenticator that fails here. For a
852/// copy with a Move authenticator, a drop counts as the data's only when the
853/// data alone explains it: the data fails its own validity check or has
854/// expired, its inputs cannot be listed, or the conflicting lock or the
855/// dropped or unseen input is one the data names, or the package holding a
856/// signer account's authenticate function is denied. Any other drop of such
857/// a copy, including the other checks of the inputs, deny rules and gas, may
858/// come from the authenticator.
859fn drop_may_come_from_signatures(
860    transaction: &SenderSignedTransaction,
861    check: FailedCheck<'_>,
862    config: &ProtocolConfig,
863) -> bool {
864    if transaction.move_authenticators().is_empty() {
865        return false;
866    }
867    let data = transaction.transaction();
868    let data_names = |kind: &InputObjectKind| {
869        data.input_objects()
870            .is_ok_and(|inputs| inputs.contains(kind))
871    };
872    match check {
873        FailedCheck::Validity(error) => {
874            !matches!(error, IotaError::TransactionExpired)
875                && !data.is_system_tx()
876                && data.validity_check(config).is_ok()
877        }
878        FailedCheck::OwnedInputs => data.input_objects().is_ok(),
879        FailedCheck::LockConflict(obj_ref) => {
880            !data_names(&InputObjectKind::ImmOrOwnedMoveObject(*obj_ref))
881        }
882        FailedCheck::Input(kind) => {
883            !data_names(kind)
884                && !matches!(
885                    kind,
886                    InputObjectKind::ImmOrOwnedMoveObject(obj_ref)
887                        if data.receiving_objects().contains(obj_ref)
888                )
889        }
890        FailedCheck::Data => false,
891        FailedCheck::Other => true,
892    }
893}

895/// Narrows the byte-derived owned inputs of an already-executed transaction to
896/// the references it consumed — the same set the main path locks — by
897/// intersecting them with the pre-execution references in its own effects;
898/// immutable inputs never appear there. A missing effects body
899/// is a storage error, never a "not executed" verdict, which would drop a
900/// committee-agreed winner other validators keep.
901fn filter_locked_inputs_by_effects(
902    authority_state: &AuthorityState,
903    digest: &TransactionDigest,
904    owned_inputs: Vec<ObjectReference>,
905) -> IotaResult<Vec<ObjectReference>> {
906    let effects = authority_state
907        .get_transaction_cache_reader()
908        .try_get_executed_effects(digest)?
909        .ok_or_else(|| IotaError::GenericAuthority {
910            error: format!(
911                "effects of already-executed transaction {digest:?} are unavailable in \
912                 post-consensus validation"
913            ),
914        })?;
915    // Owned inputs always appear in effects and immutable ones never do
916    // (`TemporaryStore::ensure_active_inputs_mutated` force-mutates every
917    // non-immutable owned input); intersecting on the full `ObjectReference`
918    // — the lock table's own key — keeps the sets identical by construction.
919    let consumed: HashSet<ObjectReference> = effects
920        .old_object_metadata()
921        .into_iter()
922        .map(|old| *old.reference())
923        .collect();
924    Ok(owned_inputs
925        .into_iter()
926        .filter(|obj_ref| consumed.contains(obj_ref))
927        .collect())
928}

930/// Finds an existing owned-object lock on `obj_ref`, walking three tiers in
931/// order:
932/// 1. `current_commit_locks` — locks acquired earlier in the same commit.
933/// 2. Consensus quarantine — locks from previous uncommitted commits.
934/// 3. Persistent DB — committed locks.
935///
936/// Returns `Ok(Some(locker))` if any tier holds a lock, `Ok(None)` if the
937/// input is free. The caller decides what to do with the result (drop with
938/// `ObjectLockConflict` for a contender, or `fatal!` if a winner is
939/// out-locked).
940fn find_existing_lock(
941    obj_ref: &ObjectReference,
942    current_commit_locks: &HashMap<ObjectReference, LockDetails>,
943    epoch_store: &Arc<AuthorityPerEpochStore>,
944) -> IotaResult<Option<LockDetails>> {
945    if let Some(&locker) = current_commit_locks.get(obj_ref) {
946        return Ok(Some(locker));
947    }
948    if let Some(locker) = epoch_store.get_quarantined_owned_object_lock(obj_ref) {
949        return Ok(Some(locker));
950    }
951    epoch_store.tables()?.get_locked_transaction(obj_ref)
952}

954/// Extracts the `ImmOrOwnedMoveObject` input references of a
955/// `UserTransactionV1` consensus transaction (excludes shared objects and
956/// packages).
957///
958/// This is the set probed for lock conflicts, not the set that gets locked.
959/// It is derived from the transaction bytes alone, where owned and immutable
960/// inputs share one kind, so it cannot tell them apart; the callers that
961/// acquire locks narrow it down first. Probing immutable references is
962/// harmless, since no tier ever holds a lock on one.
963fn extract_owned_input_objects(
964    tx: &VerifiedSequencedConsensusTransaction,
965) -> IotaResult<Vec<ObjectReference>> {
966    let Some(transaction_data) = (match &tx.0.transaction {
967        SequencedConsensusTransactionKind::External(ext) => {
968            ext.kind.as_user_transaction().map(|t| t.data())
969        }
970        SequencedConsensusTransactionKind::System(_) => None,
971    }) else {
972        return Err(IotaError::GenericAuthority {
973            error: "Expected UserTransactionV1 in extract_owned_input_objects".to_string(),
974        });
975    };
976
977    // Use SenderSignedTransaction::input_objects() rather than
978    // Transaction::input_objects() to also include objects coming from
979    // MoveAuthenticator signatures. Those can only be immutable or shared,
980    // so they widen the probe set but never the locked set.
981    let owned_objects = transaction_data
982        .input_objects()?
983        .into_iter()
984        .filter_map(|input| match input {
985            InputObjectKind::ImmOrOwnedMoveObject(obj_ref) => Some(obj_ref),
986            InputObjectKind::SharedMoveObject { .. } => None,
987            InputObjectKind::MovePackage(_) => None,
988        })
989        .collect();
990
991    Ok(owned_objects)
992}
