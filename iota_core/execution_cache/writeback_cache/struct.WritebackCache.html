fn try_multi_get_executed_effects( &self, digests: &[TransactionDigest], ) -> IotaResult<Vec<Option<TransactionEffects>>>

Overrides the default so that a transaction whose effects digest is not in memory is resolved by the store in one walk over the ledger buckets instead of two.

A transaction whose effects digest is in memory still goes through Self::try_multi_get_effects: caching its absent effects under the transaction digest would overwrite a Some entry with None, which MonotonicCache::insert reports as an invariant violation.

Source§

fn try_notify_read_executed_effects<'a>( &'a self, task_name: &'static str, digests: &'a [TransactionDigest], ) -> BoxFuture<'a, IotaResult<Vec<TransactionEffects>>>

Overrides the default for the same reason as Self::try_multi_get_executed_effects: effects already in the store are read in one walk, and only unexecuted transactions are waited for.

Reading before registering loses no wakeup, because the wait registers its waiters before reading again.
