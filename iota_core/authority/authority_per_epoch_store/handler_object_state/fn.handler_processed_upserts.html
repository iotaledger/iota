pub fn handler_processed_upserts(
    effects: &TransactionEffects,
    produced_at: CommitIndex,
) -> Vec<(ObjectKey, HandlerProcessedObject)>
Expand description

The rows one executed transaction of commit produced_at produces: a Live row for each created, mutated or unwrapped object, and a Deleted or Wrapped row for each deleted or wrapped one. A deleted shared object’s row keeps its initial shared version, taken from the consumed input’s owner, and every Deleted row names the transaction.
