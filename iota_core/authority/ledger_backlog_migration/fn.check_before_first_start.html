Expand description

Refuses a first start, before it changes anything that cannot be undone, that the one-time migration would turn into a loss or could not finish: when configured_retention, the checkpoint retention as configured, is unset while the database holds older history than its default keeps, and when the disk lacks the space the copy needs. freed is the disk space the start frees before the migration runs. Does nothing once the migration has started or is done.
