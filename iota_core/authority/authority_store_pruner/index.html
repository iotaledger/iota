AuthorityStorePruner
The AuthorityStorePruner manages the pruning process for object stores within the AuthorityStore. It includes a cancellation handle that can be used to stop the pruning task for objects.
AuthorityStorePruningMetrics
The AuthorityStorePruningMetrics tracks various metrics related to the pruning process of the AuthorityStore.
ObjectRetention
The checkpoints from which readers have asked the objects pruner to retain superseded object versions. The pruner stays below the lowest of them, and does not go past the highest executed checkpoint recorded by AuthorityStorePruner::nudge.
ObjectRetentionGuard
Keeps the objects pruner from pruning a checkpoint and every checkpoint after it, until dropped.
