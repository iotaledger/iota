Module epoch_buckets 

Source
Expand description

Per-epoch column families (“buckets”) for the stores that retain their rows epoch by epoch, so that pruning an epoch is one column-family drop instead of per-row deletes.

The history stores keep their buckets’ SST files outside the database directory (see BucketPaths).
