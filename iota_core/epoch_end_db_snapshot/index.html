Module epoch_end_db_snapshot 

Source
Expand description

Lets a consumer take a database snapshot of the perpetual store as each epoch ends.

The epoch boundary hands the epoch to the consumer and waits only until the consumer has taken its DbSnapshot; whatever the consumer reads through it afterwards runs while the node executes the next epoch.
