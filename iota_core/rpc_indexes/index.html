The RPC index store: the on-disk indexes the JSON-RPC and gRPC APIs read from. A store fills only the tables of its configured IndexGroups, plus the digest rows (see schema::HistoryBucket) that checkpoint ingest reads to skip already-indexed transactions.

jsonrpc_api and grpc_api add the read APIs, and live_scan fills the live-state tables from a live object scan or a formal-snapshot restore.

Modules§

grpc_api
The gRPC reads of the RPC index store. Every public read here fails when the store does not maintain the IndexGroup::Grpc tables.
jsonrpc_api
The JSON-RPC read surface of the RPC index store. Every public read here fails with IotaError::IndexStoreNotAvailable when the store does not maintain the IndexGroup::JsonRpc group’s tables.
live_scan
Fills the RPC index store’s live-state tables from a stream of live objects: during a rebuild from the local live object set (LiveObjectSetIndexer) and during a formal-snapshot restore (RpcIndexesRestorer). Both use one indexer per partition of the stream, and both write the rows to SST files that are ingested once every partition is done.
schema
The unified RPC index store’s schema: the tables both the JSON-RPC and gRPC read surfaces share, and the history tables that live in per-epoch column families (see super).
