Node-internal implementation of the SDK’s [TransactionBuilderLedgerClient].

NodeTransactionBuilderLedgerClient backs the SDK TransactionBuilder with a node’s local state instead of a remote gRPC or GraphQL endpoint. All reads go through [GrpcStateReader] — the same interface the gRPC server uses — so the client is available wherever that store is (fullnodes via GrpcReadStore, simulacrum in tests).

The client is ledger-only: it resolves objects, gas, and protocol parameters, but does not simulate or execute, so transactions are built with an explicit gas budget via TransactionBuilder::finish_with_budget.
