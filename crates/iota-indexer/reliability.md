The indexer collects internal metrics, which are exposed through Prometheus. Based on these collected metrics, the following table provides thresholds for quantitative requirements for Indexer monitoring.

### Quantitative Requirements:

| **Requirement**                 | **Metrics**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | **Thresholds**                                                                                                                         | Notes                         |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| **1. Checkpoint Sync Lag**      | `latest_fullnode_checkpoint_sequence_number - max_committed_checkpoint_sequence_number`                                                                                                                                                                                                                                                                                                                                                                                                                              | - **Genesis**: Lag can be > 0 not more than 35 minutes <br><br>- **Post Genesis**: Lag can be > 0 not more than 5 minutes              | Should be a Time series panel |
| **2. Data Ingestion Latencies** | `checkpoint_db_commit_latency`<br> `checkpoint_db_commit_latency_transactions`<br> `checkpoint_db_commit_latency_tx_insertion_order`<br> `checkpoint_db_commit_latency_objects`<br> `checkpoint_db_commit_latency_objects_snapshot`<br> `checkpoint_db_commit_latency_objects_history`<br> `checkpoint_db_commit_latency_events`<br> `checkpoint_db_commit_latency_event_indices`<br> `checkpoint_db_commit_latency_packages`<br> `checkpoint_db_commit_latency_tx_indices`<br> `checkpoint_db_commit_latency_epoch` | - **Genesis**: ≤ 15 minutes.<br><br>- **Post Genesis**: ≤ 15 seconds.                                                                  |                               |
| **3. DB Connection Pool Size**  | `db_conn_pool_size`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | - **Genesis sync**: Pool size can be 0 not more than 10 seconds <br><br>- **Post-genesis**: Pool size can be 0 not more than 5 seconds | Should be a Time series panel |
| 4. **JSON RPC latency**         | `req_latency_by_route`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | ≤ **1 second**.<br>                                                                                                                    |                               |

### Qualitative Requirements:

1. The indexer should be able to restart in a matter of seconds.
2. The indexer must save checkpoints in order, if a checkpoints fails to sync it should not sync subsequent checkpoints.
