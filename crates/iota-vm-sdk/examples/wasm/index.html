iota-vm-sdk in the browser

Runs transactions through the IOTA Move VM compiled to WebAssembly, entirely in the page. The VM resolves the objects it touches on demand: every object it reads is fetched from the selected network's GraphQL the moment the VM asks for it. Nothing is executed on a node — the node is only read from.

Builds a real 0x3::iota_system::request_add_stake transaction with the IOTA TypeScript SDK, then simulates it here. It is built gasless, so the VM mints a mock gas coin — exactly what a node's dev-inspect does — which is why it runs in either mode regardless of the sender's on-chain balance.
