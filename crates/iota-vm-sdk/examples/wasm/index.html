Move VM · WebAssembly · Testnet

iota-vm-sdk in the browser

Builds a real 0x3::iota_system::request_add_stake transaction with the IOTA TypeScript SDK against testnet, then simulates it in the local Move VM compiled to wasm. The VM resolves the objects it touches on demand: every object it reads — inputs and the dynamic-field children staking walks — is fetched from testnet GraphQL the moment the VM asks for it. Nothing is executed on a node.
