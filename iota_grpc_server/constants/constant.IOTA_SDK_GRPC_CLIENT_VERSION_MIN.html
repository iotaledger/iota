Lowest iota-sdk-grpc-client version able to decode this node’s gRPC responses, sent in the X_IOTA_SDK_GRPC_CLIENT_VERSION_MIN header of every response.

Raise it to the SDK release that ships a wire-visible change (a new enum variant, a new oneof case, …) once that release is out, so clients on an older SDK fail their calls instead of choking on values they cannot decode. scripts/check_min_iota_sdk_client_version.py fails in CI when a change to the BCS schema of iota-sdk-types requires raising it. A change to the proto definitions is not checked and has to be raised by hand.
