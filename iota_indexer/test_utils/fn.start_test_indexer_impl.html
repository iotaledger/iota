Expand description

Starts an indexer reader or writer for testing depending on the reader_writer_config.

§Note

For IndexerTypeConfig::Writer when data_ingestion_path is Some, the data ingestion path will be exclusively used to ingest data into the indexer. To force the indexer to sync from the fullnode via gRPC, set data_ingestion_path to None and it will use the rpc_url to stream checkpoints from the fullnode gRPC endpoint.
