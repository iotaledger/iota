A trait for databases that can be restored from a formal snapshot.

Required Methods§

Source

fn insert_partition( &self, file_metadata: FileMetadata, bytes: Bytes, expected_checksum: &[u8; 32], ) -> impl Future<Output = Result<()>> + Send

Inserts a partition of live objects.

The checksum of the partition can be computed as the SHA3 hash of all objects’ digests included. Then it can be verified against the given expected value.

An implementation that blocks its thread can stall downloads while it runs. Such an implementation should move its work to the blocking pool.

Provided Methods§

Source

fn max_concurrent_inserts(&self) -> NonZeroUsize

How many partitions the reader may insert at the same time. Each insert in progress holds one downloaded partition in memory.

A value above one helps only if insert_partition does not block its thread.
