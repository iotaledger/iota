fn insert_partition( &self, file_metadata: FileMetadata, bytes: Bytes, expected_checksum: &[u8; 32], ) -> impl Future<Output = Result<()>> + Send

Inserts a partition of live objects.

The checksum of the partition can be computed as the SHA3 hash of all objects’ digests included. Then it can be verified against the given expected value.
