fn get_owner_objects_page( &self, owner: Address, cursor: Option<IndexCursor>, limit: usize, filter: Option<IotaObjectDataFilter>, ) -> StateReadResult<Page<Object, OwnedObjectCursor>>

Returns one page of the owner’s objects that match filter. cursor is exclusive; next_cursor is None when there is no next page.

A page reads a limited number of objects, so it can hold fewer than limit objects, even none, while has_next_page is set.
