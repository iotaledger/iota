Expand description

Recovers the objects created by the migration transactions of a MigrationTxData by re-executing them. Executing needs the Move VM, so these operations live here instead of next to the data type in iota-config.

Required Methods§

Source

Executes the migration transaction identified by digest and returns the vector of objects created by the execution.
