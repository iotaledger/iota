Multiaddr wrapper for IOTA.

The public API differs by target. On wasm32 only the parts needed to type-check and serialize on-chain validator metadata are available; the address-parsing and networking helpers are native-only, since they pull in dependencies that do not build for wasm. The wasm module documents what the wasm build provides and why.
