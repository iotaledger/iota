# Coins and Objects

<ERC721/>

The IOTA L1 can create Objects, also called native Objects. To use these Objects on L2, you have
an ERC20 contract called `ERC721Objects`, which contains all L1 Objects owned by the chain. The following guides will show you how to [mint your own L1 Object from L2](./mint-Object.mdx) and use it with the `ERC721Objects` contract.
