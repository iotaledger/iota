# Native Token

<ERC20/>

The IOTA L1 has functionality to create L1 tokens, also called native tokens. To use these native tokens on L2 you need to transfer the tokens to L2 using IOTA toolkit/bridge. The following guides will show you how to create and use native tokens on L2.
[mint your own L1 token from L2](create-coin.mdx),
so it can be used like any other ERC20 token with some additional features.
