# Create a Coin

You can create Native Tokens (IOTA objects on L1) using Move packages. In the newest updates, you cannot create Native Tokens from L2 to L1 directly, but you can transfer the Native Tokens you created on L1 to L2 using a toolkit/bridge. Follow the [Creating an ERC-721-like NFT](../../../../developer/evm-to-move/creating-token.mdx)
