# Get On-Chain NFT Data

This guide explains how to use the `getObjectBCS` function within a smart contract to fetch information about a specific on-chain NFT on the IOTA network.

<GetNftMetadata />

## How to Use the `getObjectBCS` Function

The `getObjectBCS` function retrieves data for an NFT based on its identifier. It returns a bytes, which contains various properties of the NFT like the issuer, metadata, owner, and NFTID. To use this function, you need to create a function in your smart contract that calls `getObjectBCS` and processes its return value, as shown in the example contract below:

## Example Code

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

import "@iota/iscmagic/ISC.sol";
import "@iota/iscmagic/ISCTypes.sol";

contract NFTMetadata {
    function fetchNFTData(IotaObjectID id) public view returns (bytes memory) {
        bytes memory nftData = ISC.sandbox.getObjectBCS(id);
        return nftData;
    }
}
```
