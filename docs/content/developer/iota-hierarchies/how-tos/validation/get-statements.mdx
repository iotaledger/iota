# Get Statements

This guide demonstrates how to retrieve statements from a federation using the offchain API.

### Prerequisites

- An existing hierarchy on the IOTA network
- A funded client with write access
- A federation with statements already added

### Overview

The get statements API allows you to retrieve all federation properties and statements that have been added to a federation.

### Key Points

- **Federation Properties**: The retrieved data includes all federation properties and statements
- **Multiple Statements**: Federations can contain multiple statements with different names and values
- **Multi-level Names**: Statement names can have multiple levels (e.g., ["Example LTD 2", "Example LTD 3"])
- **Read-Only Access**: Retrieving statements only requires read access to the hierarchy
