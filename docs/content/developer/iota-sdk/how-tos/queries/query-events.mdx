# Query Events

import IotaSdk from '../../../../_snippets/developer/iota-sdk/sdk.mdx';

<IotaSdk />

This guide shows you how to query events emitted by a Move package using the IOTA SDK's [GraphQL client](/developer/references/iota-graphql).

## Prerequisites

- The IOTA SDK installed for your target language
- The fully qualified event type you want to query (`<package>::<module>::<EventName>`)

## Steps

### 1. Initialize the GraphQL Client

Create a client connected to the IOTA Testnet.
