# Query Owned Objects

import IotaSdk from '../../../../_snippets/developer/iota-sdk/sdk.mdx';

<IotaSdk />

This guide shows you how to list the [objects](/developer/iota-101/objects/object-model) owned by an IOTA address using the IOTA SDK's [GraphQL client](/developer/references/iota-graphql).

## Prerequisites

- The IOTA SDK installed for your target language
- A valid IOTA address on the testnet

## Steps

### 1. Initialize the GraphQL Client

Create a client connected to the IOTA Testnet.
