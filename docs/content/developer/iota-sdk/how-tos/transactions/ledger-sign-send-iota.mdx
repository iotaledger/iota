# Sign and Send IOTA with a Ledger

<IotaSdk />

This how-to demonstrates how to sign an IOTA transfer with a key held on a Ledger hardware wallet, or on the Speculos emulator, and execute it on localnet.

:::info
This example runs on **localnet**. Make sure you have a local IOTA node running before executing the code.
:::

{/* The embeds are pinned to an iota-rust-sdk commit because the revision in docs/site/iota-sdk-references.rev predates the Ledger examples. Switch them to the SDK_REV placeholder once that revision includes them. */}

## Prerequisites

- The IOTA SDK installed for your target language, with Ledger support:
  - Rust: the `graphql`, `ledger-hid` and `ledger-speculos` features of the `iota-sdk` crate.
  - Go, Python, Kotlin, Swift and C#: the released packages cannot connect to a device over USB. To use one, build the bindings with `make <language>` in a checkout of [iota-rust-sdk](https://github.com/iotaledger/iota-rust-sdk).
  - WASM/TS: no additional setup. The bindings reach the device through a transport you implement, see [Use Another Transport](#use-another-transport).
- A running local IOTA node
- A Ledger device or the Speculos emulator, set up as described below

On Linux, building the SDK with USB support needs the `libudev` development package (`libudev-dev` on Debian and Ubuntu).

## Set Up the Device

<Tabs groupId="ledger-device" queryString>
  <TabItem value="device" label="Ledger device" default>

1. Install the IOTA app on the device with Ledger Live.
2. Connect the device over USB and unlock it.
3. On Linux, install the [Ledger udev rules](https://github.com/LedgerHQ/udev-rules) so that a regular user can open the device.

  </TabItem>
  <TabItem value="speculos" label="Speculos emulator">

[Speculos](https://github.com/LedgerHQ/speculos) emulates a device running the IOTA app, so you can develop without hardware.

1. Start the emulator with Docker from a checkout of [iota-rust-sdk](https://github.com/iotaledger/iota-rust-sdk):

   ```bash
   make speculos-start
   ```

2. Set the `LEDGER_SIMULATOR` environment variable when you run the example, which then connects to the emulator instead of a device.
3. Approve the requests in the emulator's web interface at `http://127.0.0.1:5001`.

  </TabItem>
</Tabs>

## Use Another Transport

On Android, on iOS and in the browser the SDK cannot open USB devices. To reach a device there:

1. Implement `LedgerTransport` on top of your link to the device, such as Bluetooth through Ledger's mobile SDKs, or WebHID and WebUSB in the browser. Its `exchange` method receives an APDU command and returns the device's answer, which ends with the two-byte status word.
2. Create the `Ledger` from that transport with `Ledger.fromTransport`.

The WASM/TS tab in [step 2](#2-connect-to-the-ledger-and-open-the-iota-app) shows a transport over a TCP socket.

## Sign Transactions the Device Cannot Display

The IOTA app shows what a transaction does when it can work that out from the transaction and its input objects. To sign a transaction the app cannot interpret, enable blind signing in the settings of the IOTA app on the device.
