---
title: IOTA SDKs
---

IOTA provides developer kits that act as wrappers for the IOTA API.

## IOTA dApp Kit

[IOTA dApp Kit](../ts-sdk/dapp-kit/index.mdx) is a web frontend SDK that interacts with the IOTA API. It is available as an NPM package.

## IOTA TypeScript SDK

The IOTA TypeScript SDK documentation is available in the [IOTA TypeScript SDK section](../ts-sdk/typescript/index.mdx).

## IOTA SDK (Rust core with language bindings)

The [IOTA SDK](../iota-sdk/getting-started/rust.mdx) is a modular Rust SDK with bindings for
[Go](../iota-sdk/getting-started/go.mdx), [Kotlin](../iota-sdk/getting-started/kotlin.mdx),
[Python](../iota-sdk/getting-started/python.mdx), [Swift](../iota-sdk/getting-started/swift.mdx),
[C#](../iota-sdk/getting-started/csharp.mdx), and [WASM/TypeScript](../iota-sdk/getting-started/wasm.mdx).
