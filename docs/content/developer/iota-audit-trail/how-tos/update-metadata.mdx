# Update Metadata

This guide shows how to manage the two-tier metadata system on an Audit Trail: **immutable metadata** (set once at creation) and **updatable metadata** (can be changed or cleared at any time by an authorized role).

## Prerequisites

- An existing Audit Trail on the IOTA network
- A capability with `UpdateMetadata` permission (e.g., a `MetadataAdmin` role)
- Familiarity with [creating an Audit Trail](./create-audit-trail.mdx)

## Expected Behavior

- **Immutable metadata** (name and description) never changes after trail creation.
- **Updatable metadata** can be freely changed or cleared by a holder of a `MetadataAdmin` capability.
- Typical use: store a status summary (e.g., `"Status: Active"`) that evolves as the trail progresses.
