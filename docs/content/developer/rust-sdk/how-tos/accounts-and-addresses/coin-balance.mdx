# Get Coin Balance

This guide explains how to retrieve coin balances for a given IOTA address using the IOTA SDK's [GraphQL client](/developer/references/iota-graphql). You will learn how to list individual [coin objects](/developer/iota-101/objects/object-model) held by an address and query the total aggregated balance.

:::info
The examples below connect to the **IOTA Testnet** via the GraphQL client. Make sure you are using a valid testnet address.
:::

## Prerequisites

Before running these examples, make sure you have:

- The IOTA SDK installed for your target language
- A valid IOTA address on the testnet

## Expected Output

Running any of the above examples should produce output in the following format:

```bash
Coin = 0x<object-id>, Coin Type = 0x2::iota::IOTA, Balance = <amount-in-nanos>
Coin = 0x<object-id>, Coin Type = 0x2::iota::IOTA, Balance = <amount-in-nanos>

Total Balance = <total-amount-in-nanos>
```

:::tip
Balances are denominated in **nanos** (the smallest IOTA unit). To convert to IOTA, divide by `1_000_000_000`.
:::
