# Basic Account Abstraction Example

## About Account Abstraction

Account abstraction in IOTA Move lets you attach a custom `authenticate` function to an account object. The account
stores a reference to that function as a dynamic field, and the runtime can invoke the authenticator during
transaction execution. The reference is created from on-chain package metadata, which validates that the
authenticator is compatible with the account type.

This example shows:

- Defining an account object and sharing it publicly.
- Linking the account to an authenticator function at runtime.
- Implementing a minimal authenticator that checks a message value.

### Expected Behavior

After publishing the package, anyone can call `link_auth` to attach the authenticator to the shared account. The
example authenticator accepts a message string and succeeds only when the message equals `"hello"`.
