## About account abstraction

Account Abstraction lets you attach a Move `authenticate` function to a shared account object. The runtime will call that function to decide whether a transaction where the account is the sender is allowed.

In this example, the authenticator enforces **multi-party approval** by checking on-chain approvals stored as
dynamic fields on the account object.

## What this example shows

This how-to demonstrates how Account Abstraction can be used to build a **dynamic multisig account**:

- Create a shared account object with members, weights and threshold.  
- Store per-account proposed transaction digests and approvals on-chain.  
- An `authenticate` function that verifies a transaction digest has enough member approvals before allowing the account to send the TX.  
- How to update members/threshold and rotate authenticators.

After deploying and using this dynamic multisig account implementation:

- A shared abstract account address is created that represents the multisig wallet.
- Account state (members, weights, threshold, proposed transactions) is stored as dynamic fields under the account object.
- Members can propose transactions by submitting only the transaction digest on-chain.
- Other members can approve the same transaction digest, and approvals are accumulated by weight, not by count.
- When a transaction is submitted with the multisig account as the sender, the attached authenticator is executed automatically by the runtime.
- The transaction is allowed only if total approval weight ≥ threshold; otherwise it is rejected during validation.
- Members, weights, threshold, and even the authenticator itself can be updated without changing the account address.
- Old approvals from removed members are automatically ignored, keeping the approval logic consistent.

## Expected Behavior

- After the account is created, members propose and approve transaction digests on-chain.
- Any transaction sent from the account executes only if the attached authenticator confirms that the total approval weight meets the configured threshold.
