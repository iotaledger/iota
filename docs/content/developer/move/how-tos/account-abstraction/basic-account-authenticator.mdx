# Create a Basic Account Authenticator

import AccountAbstraction from '../../../../_snippets/developer/move/aa.mdx';

<AccountAbstraction />

This How-To demonstrates how to create and attach a basic authenticator to an account.
If you want to learn more about the concepts of Account Abstraction, check out the [Account Abstraction Introduction](../../explanations/account-abstraction.mdx).

## Example Code

1. Define an account object.
```move file=<rootDir>/examples/move/account/sources/account.move#L10-L12
```
2. Initialize the account by creating a shared object.
```move file=<rootDir>/examples/move/account/sources/account.move#L16-L21
```
3. Build the authenticator function reference by passing the `package`, `module`, and `function` names of any `authenticate` function to [`authenticator_function::create_auth_function_ref_v1`](../../../references/framework/devnet/iota/authenticator_function.mdx#function-create_auth_function_ref_v1).
```move file=<rootDir>/examples/move/account/sources/account.move#L24
```  
4. Create the account with that authenticator function reference by calling [`account::create_account_v1`](../../../references/framework/devnet/iota/account.mdx#function-create_account_v1).
```move file=<rootDir>/examples/move/account/sources/account.move#L25
```
5. Use the wrapper function that contains both calls above to link the account to the authenticator function.
```move file=<rootDir>/examples/move/account/sources/account.move#L23-L26
```
6. Define the `authenticate` function used by the account. In this example, it succeeds only when the provided message equals `"hello"`.
```move file=<rootDir>/examples/move/account/sources/account.move#L28-L46
```

## Verify the Result

- A transaction authorized through this authenticator succeeds when the message argument is `"hello"`.
- The same transaction fails when the message argument differs.

## Expected Behavior

After publishing the package, anyone can call `link_auth` to attach the authenticator to the shared account. The
example authenticator accepts a message string and succeeds only when the message equals `"hello"`.
