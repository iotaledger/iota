# Basic Account Abstraction Example

## About Account Abstraction

Account Abstraction in IOTA Move allows an account to delegate transaction authorization to a custom Move
`authenticate` function.  
Instead of verifying cryptographic signatures, the runtime executes this function during transaction validation
to decide whether the transaction is allowed.

The authenticator function is referenced on-chain via package metadata and attached to a shared account object.

## What This Example Shows

This how-to demonstrates the **minimum building blocks** required to use Account Abstraction:

- Defining a shared account object
- Attaching an authenticator function at runtime
- Executing a transaction that is authorized via the authenticator

This example intentionally avoids multisig, thresholds, or off-chain coordination to focus on core mechanics.
