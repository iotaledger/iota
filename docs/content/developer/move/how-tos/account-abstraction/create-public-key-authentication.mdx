## Expected Behavior
- The account verifies transaction signatures against the stored public key using the configured cryptographic scheme (Ed25519, Secp256k1, or Secp256r1).
- Only transactions with valid signatures from the corresponding private key are accepted and executed.
- The public key and authenticator can be rotated together to update account security.
