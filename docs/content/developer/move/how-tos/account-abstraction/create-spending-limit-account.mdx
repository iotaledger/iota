## Expected Behavior
- Transactions with withdrawal amounts exceeding the spending limit fail with `ESpendingLimitExceeded` error.
- Multiple withdrawal commands in a single transaction are summed and checked against the limit.
- The spending limit decreases by the withdrawn amount after each successful withdrawal.
- Withdrawals from insufficient balance reserves fail with `EInsufficientBalanceReserve`.
- Only valid `withdraw_from_balance_reserve` calls from the correct package are counted.
