This how-to demonstrates how to build a dynamic multisig account using Account Abstraction, with on-chain approvals, weighted members, and threshold-based authorization.
If you want to learn more about the concepts of Account Abstraction, check out the [Account Abstraction Introduction](../../../explanations/account-abstraction.mdx).





## Expected Behavior

- After the account is created, members propose and approve transaction digests on-chain.
- Any transaction sent from the account executes only if the attached authenticator confirms that the total approval weight meets the configured threshold.
