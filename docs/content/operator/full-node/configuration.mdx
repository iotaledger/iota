The IOTA Full Node configuration file is a YAML file that you can use to configure your node.
To smooth the setup process you can use an example configuration file and modify it to your needs.


Depending on the network you want to connect to, you need to adjust the peering configuration in the configuration file and download a correct genesis blob (for more details see [genesis](../common/genesis.mdx)) page.
Download the latest version of the IOTA Full Node configuration and blob files for the network you want to connect to:
<Tabs groupId="node-config">
    <TabItem value="testnet" label="Testnet">
For testnet you can use the following commands to download necessary files:
    - Default node template: [fullnode-template-testnet.yaml](https://github.com/iotaledger/iota/raw/develop/crates/iota-config/data/fullnode-template-testnet.yaml).
```shell
wget https://github.com/iotaledger/iota/raw/develop/crates/iota-config/data/fullnode-template-testnet.yaml
```
    - Genesis blob file: [genesis.blob](https://dbfiles.testnet.iota.cafe/genesis.blob).
```shell
curl -fLJO https://dbfiles.testnet.iota.cafe/genesis.blob
```
    </TabItem>
    <TabItem value="devnet" label="Devnet">
For devnet you can use the following commands to download necessary files:
- Default node template:  [fullnode-template-devnet.yaml](https://github.com/iotaledger/iota/raw/develop/crates/iota-config/data/fullnode-template-devnet.yaml)
```shell
wget https://github.com/iotaledger/iota/raw/develop/crates/iota-config/data/fullnode-template-devnet.yaml
```
- Genesis blob file: [genesis.blob](https://dbfiles.testnet.iota.cafe/genesis.blob).
```shell
curl -fLJO https://dbfiles.devnet.iota.cafe/genesis.blob
```

    </TabItem>
</Tabs>


This default template uses default ports, archive and pruning settings and also covers peering configuration for the selected network.
If you're fine with the default settings, you can use the template as is and continue with the node setup either [using Docker](docker.mdx) or [build it from source](source.mdx).

For more specific guidance on how to configure your node to suit you needs, e.g. configure snapshot, refer to the following sections:
  - [Network](../common/network.mdx) - peering configuration for the node.
  - [Pruning](../common/pruning.mdx) - how to prune your IOTA Full Node to leverage storage space.
  - [Snapshots](../common/snapshots.mdx) - how to configure formal and RocksDB snapshots for your IOTA Full Node.
  - [Archives](../common/archives.mdx) - how to configure archives for your IOTA Full Node.
  - [Genesis](../common/genesis.mdx) - more details on genesis.
