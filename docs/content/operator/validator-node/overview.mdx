Validators on the IOTA network run special nodes and have additional tasks and responsibilities beyond those of full node operators.

## Requirements to Run a Validator Node on IOTA

To run an IOTA validator node, you must have a minimum of **2 million IOTA** in your staking pool to join the validator set. For setup and configuration, refer to the [Docker Setup](docker.mdx) or [Systemd Setup](systemd.mdx) guides, which also include instructions on the tasks required after joining the validator set.

Specific steps you must take include:

- Install and configure IOTA validator node  
- Key management  
- Software updates
- On-chain commands
- Update the Gas Price Survey
- Reporting other validators
