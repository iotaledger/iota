# Restore From Seed or Stronghold

If you have lost your mnemonic, you can still recover your account provided you have access to your seed or
`.stronghold` file.

<Seed />

## Back Up a Seed From a Firefly Profile

You can export you seed by clicking on the `...` menu, and then clicking `Backup Seed`.

## Back Up a Seed From a `.stronghold` file

:::info Not Recommended

If you are using Firefly, we recommend using the [Backup Seed](#back-up-from-a-seed-from-firefly-profile) option from the Firefly menu.
Using a stronghold file directly should only be done if you don't have a profile in Firefly or if you are using a different wallet.

:::

You can use your `.stronghold` backup file to obtain your wallet's seed.

If don't know where your `.stronghold` file is, click on the `...` menu and select the `Copy system profile location`. 

<Tabs groupId="os" queryString>
   <TabItem value="windows" label="Windows">
      ![Copy Stronghold Location](/img/about-iota/iota-wallet/how-to/restore-account/windows/copy-stronghold-location.png)
   </TabItem>
   <TabItem value="linux" label="Linux">
      ![Copy Stronghold Location](/img/about-iota/iota-wallet/how-to/restore-account/linux/copy-stronghold-location.png)
   </TabItem>
   <TabItem value="macos" label="MacOS">
      ![Copy Stronghold Location](/img/about-iota/iota-wallet/how-to/restore-account/macos/copy-stronghold-location.png)
   </TabItem>
</Tabs>

<Tabs groupId="os" queryString>
   <TabItem value="windows" label="Windows">
      Next, you should click on the burger menu in the top left and `Firefly > Backup Seed`.

      ![Backup Seed Menu](/img/about-iota/iota-wallet/how-to/restore-account/windows/backup-seed-menu.png)
   </TabItem>
   <TabItem value="linux" label="Linux">
      Next, you should click on `Electron > Backup Seed`.

      ![Backup Seed Menu](/img/about-iota/iota-wallet/how-to/restore-account/linux/backup-seed-menu.png)
   </TabItem>
   <TabItem value="macos" label="MacOS">
      Next, in the menu bar click on `Firefly > Backup Seed`.

      ![Backup Seed Menu](/img/about-iota/iota-wallet/how-to/restore-account/macos/backup-seed-menu.png)
   </TabItem>
</Tabs>

Once you have the `.stronghold` file at hand, you can drag and drop it into Firefly's Stronghold Backup.

<Tabs groupId="os" queryString>
   <TabItem value="windows" label="Windows">
      ![Drag and Drop Stronghold](/img/about-iota/iota-wallet/how-to/restore-account/windows/drag-and-drop-stronghold.png)
   </TabItem>
   <TabItem value="linux" label="Linux">
      ![Drag and Drop Stronghold](/img/about-iota/iota-wallet/how-to/restore-account/linux/drag-and-drop-stronghold.png)
   </TabItem>
   <TabItem value="macos" label="MacOS">
      ![Drag and Drop Stronghold](/img/about-iota/iota-wallet/how-to/restore-account/macos/drag-and-drop-stronghold.png)
   </TabItem>
</Tabs>

Firefly will then prompt you to enter your password to unlock the `.stronghold` file.

<Tabs groupId="os" queryString>
   <TabItem value="windows" label="Windows">
      ![Enter Password](/img/about-iota/iota-wallet/how-to/restore-account/windows/enter-password.png)
   </TabItem>
   <TabItem value="linux" label="Linux">
      ![Enter Password](/img/about-iota/iota-wallet/how-to/restore-account/linux/enter-password.png)
   </TabItem>
   <TabItem value="macos" label="MacOS">
      ![Enter Password](/img/about-iota/iota-wallet/how-to/restore-account/macos/enter-password.png)
   </TabItem>
</Tabs>

Firefly will then show you the seed it restored from the `.stronghold` file. 

<Tabs groupId="os" queryString>
   <TabItem value="windows" label="Windows">
      ![Copy Seed](/img/about-iota/iota-wallet/how-to/restore-account/windows/copy-seed.png)
   </TabItem>
   <TabItem value="linux" label="Linux">
      ![Copy Seed](/img/about-iota/iota-wallet/how-to/restore-account/linux/copy-seed.png)
   </TabItem>
   <TabItem value="macos" label="MacOS">
      ![Copy Seed](/img/about-iota/iota-wallet/how-to/restore-account/macos/copy-seed.png)
   </TabItem>
</Tabs>

With your seed at hand, you can [import your wallet using the IOTA Web Wallet](../getting-started.mdx#importing-an-existing-wallet).
