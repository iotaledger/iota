# IOTA Bounty Program

The IOTA Bounty Program connects the community with funded tasks that help improve the IOTA products and ecosystem.

## Current Active Programs

<Cards>
    <Card title="SDK Testing" href="https://github.com/orgs/iotaledger/projects/97/views/1">

    </Card>
</Cards>

## How It Works

To work on an open issue, pick a task from the board that matches your skills and start working on it in the linked repository.

To create your own bounty, open a new `Bounty` issue using the provided template in the corresponding repository and fill in the details. Then link the issue to the board so others can find and work on it.
