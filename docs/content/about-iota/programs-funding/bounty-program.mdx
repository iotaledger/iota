# IOTA Bounty Program

The IOTA Bounty Program connects the community with funded tasks that help improve the IOTA ecosystem. It currently includes a single active program hosted on a GitHub Project board, and more programs will be added in the future.

## Current Active Programs

<Cards>
    <Card title="SDK Testing" href="https://github.com/orgs/iotaledger/projects/97/views/1">
    Help us test and improve the new IOTA SDK supporting Rust, Go, Kotlin and Python.
    </Card>
</Cards>

## How It Works

- Browse open issues on the board and pick a task that matches your skills.
- Work on the issue and submit your contribution through the linked repository.
- Community members can also create new issues and link them to the board so others can work on them.
