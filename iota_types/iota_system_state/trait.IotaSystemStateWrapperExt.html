fn advance_epoch_safe_mode( &self, params: &AdvanceEpochParams, object_store: &dyn ObjectStore, protocol_config: &ProtocolConfig, ) -> (Object, Object)

Advances epoch in safe mode natively in Rust, without involking Move. This ensures that there cannot be any failure from Move and is guaranteed to succeed. Returns the old and new inner system state object.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
