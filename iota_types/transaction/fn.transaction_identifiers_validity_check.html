pub fn transaction_identifiers_validity_check(
    signed_tx: &SenderSignedTransaction,
) -> UserInputResult
Expand description

Rejects a signed transaction that carries a system transaction kind, or an identifier move-core rejects: in Move call module and function names, and in the type arguments of Move calls, MakeMoveVector commands and Move authenticators.

Independent of the protocol config, so the caller gates it; the consensus block verifier uses it to reject exactly the blocks a decoder that follows the move-core rules would fail to decode.
