Expand description

Returns Ok(()) if no input or receiving object’s coin type is on a deny list for the given address.

With cur_epoch = None, the check reads the latest deny-list value, so denials take effect immediately; the result depends on how far the validator’s execution has progressed, making it suitable only for validator-local decisions, such as pre-consensus admission. With Some(epoch), the read is gated to the value settled before that epoch (entries written in epoch E activate in E + 1), making the result deterministic across validators; required where all validators must agree on the outcome, such as post-consensus validation.
