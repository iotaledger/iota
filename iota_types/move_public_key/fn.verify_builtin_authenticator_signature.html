Expand description

Verifies a built-in authenticator signature.

signature_bytes is a UserSignature in wire format (flag || payload) whose scheme must be the scheme of public_key. This format is consistent for all schemes: Ed25519, Secp256k1, Secp256r1, MultiSig, and Passkey.

tx_data_bytes is the BCS-encoded Transaction used to reconstruct the signing message as IntentMessage(Intent::iota_transaction(), tx_data).

The multisig and passkey verification rules are taken from protocol_config.
