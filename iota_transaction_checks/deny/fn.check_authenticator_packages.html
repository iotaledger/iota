Check that no MoveAuthenticator authenticates through a denied package.

The package holding the authenticate function is named only by the account’s AuthenticatorFunctionRef: the call is assembled during execution, and the reference is a runtime one, so the package appears in neither the transaction’s commands nor any linkage table. It is therefore checked here rather than alongside a transaction’s commands in check_transaction_for_validation.

Call it once the references have been loaded, over every authenticator the transaction carries, and before any authenticator runs.
